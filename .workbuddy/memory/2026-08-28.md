# 2026-08-28

- 排查"Point Light 在 Play Mode 消失"：并非 Unity 限制，而是 `RenderingOptimizationState`（`GameManager.ApplyPerformanceOptimizations` → `ApplyTo`）在运行时把**包含 MonsterActor 或 ParticleSystem 的层级**内所有非 Directional 光源（Point/Spot）`enabled=false` 并关阴影。开关是 `GameManager.enableA4ImportedLightOptimization`（默认 true，且 `ImportedLightOptimizationEnabled` 在 Instance==null 时也返回 true）。解法：把点光源移出怪物/VFX 层级，或在 GameManager 关 A4（性能权衡），或用 emissive+bloom 代替。相关文件：`Assets/Scripts/Presentation/Rendering/RenderingOptimizationState.cs`、`Assets/Scripts/Systems/GameFlow/GameManager.cs`。
