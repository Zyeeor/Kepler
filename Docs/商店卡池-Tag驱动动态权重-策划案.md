# 商店卡池 — Tag 驱动动态权重 策划案

> **状态：** 草案 / 待 Owner 确认（含开放项，见 §9）
> **定位：** 本文是「波次结束进商店 → 选卡升级」阶段的卡池选取与刷新规则设计案。
> **Authority：** 本文低于 `.vibe/doc/Canonical/**`。凡涉及卡牌内容、作用域、Offer 时点等，以 Canonical 与最新 Owner Decision 为准；本文只定义「上层如何选/刷卡」，不改任何卡牌内容。
> **来源对接：** 卡牌内容真源 = `.vibe/doc/Canonical/Content/Card_System_Current_Truth_v1.1.md`（受保护，不在本文修改）；节奏与 Offer 结构 = `.vibe/doc/Canonical/Content/Encounter_CardOffer_Baseline_v1.0.md`。

## 1. 设计目标

商店阶段的卡池选取，必须同时兑现三个目标，缺一不可：

1. **能攒成一个完整流派**：玩家围绕投资方向，能顺利集齐一条流派链，获得成型的玩法体验。
2. **一定认识到特殊机制卡的乐趣**：整局必然见识到「改变规则」的全局质变卡，而非整局没露面。
3. **不锁死在单一怪物**：流派成型后自然把焦点让给其他方向，且每局、每次选择都不趋同。

对应两处对 Canonical 的**扩展**（Canonical 当前留空，非冲突）：

- 波次结束条件 = **时间结束**（倒计时归零即结束，与残余敌人数无关）；
- 每次商店的**每张卡有 1 次刷新机会**。

---

## 2. 核心思路：保证从「空间」移到「时间」

不采用「位置一=横向、位置二=流派、位置三=探索」的**固定三槽**，因为固定槽位会让玩家形成逐次预期（「中间那张肯定是我的流派」），导致 BD 体验趋同。

改为 **配额 + 动态组合 + 每局微扰动（方案 C）**：

> 三个设计目标不绑定到「某个槽每次都出」，而是变成**一整局的产出配额**；每一次三选一的三张，从「当前还欠哪些配额」里动态组合，顺序被打散。

结果：

- 玩家**逐次无法预判**这次三张是什么组合（悬念回来）；
- 但**一局结束回看，三个目标都被保证**（成流派、见特殊卡、探索窗口一直开）；
- **每局基调微扰动**，局与局之间也不同。

## 3. Tag 字段设计

用一个独立的 Tag 配置驱动全部选/刷逻辑，抽卡代码只读 Tag、不硬编码任何 Card ID。

> **重要边界：** 卡牌内容真源受保护，Tag **不写入真源正文**，而是一份用 `Card ID` 关联真源的**独立配置**（落点见 §8）。

每张卡的 Tag 含 5 个维度：

| 字段 | 类型 | 含义 | 来源 |
|---|---|---|---|
| `cardId` | string | 关联真源，如 `GL-S01` | 真源 |
| `slotClass` | 枚举 | `Horizontal` / `Build`（探索为「剩余」，不显式标） | 可由真源「分类」字段**自动生成** |
| `kind` | 枚举 | `Mechanic`（机制卡）/ `Numeric`（数值卡） | **人工确认一次** |
| `buildLine` | string | 流派归属，如 `Gluttony.Devour`；数值卡可空 | **人工确认一次** |
| `isSpecial` | bool | 是否全局质变（特殊卡），用于露面下限 | 可由真源「分类」**自动生成** |

- `slotClass` / `isSpecial`：真源「分类」字段每张都有且已 Owner Review Passed，可**全自动生成**，零人工。
- `kind` / `buildLine`：属于新增设计判断，需一次性人工裁定（初稿采用本项目已完成的逐卡分类，见 §7 与 §9 开放项）。

## 4. 权重公式：Tag 是静态身份，权重是「Tag × 当前状态」实时算

同一张卡在不同时刻权重不同，取决于它的 Tag 撞上了当前哪些「欠账 / 进度」。

单张卡的**首次抽取 / 刷新**权重：

```
Weight(card) =
    BaseWeight
  × QuotaFactor(card.tag)        // 这张卡能补的配额还欠多少 → 越欠越高
  × BuildFactor(card.tag)        // 它的流派成型到哪一步
  × InvestmentFactor(card.tag)   // 玩家对该罪投资（带封顶）
  × SuppressionFactor(card.tag)  // 该类/该罪近期出太多 → 压低
  × SessionBias(card.tag)        // 本局微扰动基调（方案 C）
  × HardMask(card)               // 废牌过滤：0 或 1
```

每个 Factor 只看 Tag 的某个维度，职责单一、可独立调参。

## 5. 各 Factor 具体规则

### 5.1 HardMask（最先算，为 0 直接淘汰）

以下任一成立 → 返回 0（该卡不参与本次）：

1. 已达该卡叠层上限（`Stack Max`）；
2. 只能拿一次（Unique / Standalone）且已取得；
3. 前置不满足 / 对当前合法对象零效果（运行时判定）；
4. 本次 offer 已在别处出现的同 Card ID。

### 5.2 QuotaFactor（配额欠账 —— 动态组合引擎）

- 判定这张卡能补哪类配额：
  - `isSpecial = true` → 补**特殊卡配额**；
  - `kind = Mechanic` 且所属流派**未成型** → 补**流派配额**；
  - 其余合法卡 → 可充当**探索配额**。
- 该类配额**还欠越多、剩余 offer 次数越紧** → 倍率越高（软保底）。
- 例：特殊卡整局下限 3、已出 0、只剩 2 次 offer → 特殊卡 QuotaFactor 猛拉高。

### 5.3 BuildFactor（成型进度）

- 卡所属 `buildLine` **未成型** 且本卡是该链机制卡 → ×高（**未成型优先**，帮成型）；
- 该流派**已成型**：
  - 本卡是机制卡（多半已被取走）→ 不影响；
  - 本卡是该罪**数值卡** → ×低（**成型即降级**，只作锦上添花）。
- 「成型」判定见 §6。

### 5.4 InvestmentFactor（投资加权，带封顶）

- 按玩家对 `buildLine` 对应罪的投资数给乘数；
- **到该流派成型所需机制卡数即封顶**，之后不再增长 → 防止单罪权重滚雪球霸屏。

### 5.5 SuppressionFactor（近期抑制）

- 某 `buildLine` / 某「分类」在最近 1～2 次 offer 中占比过高 → ×0.70~0.85，把机会让给别的方向。这是对冲「锁死单一」的关键反向力。

### 5.6 SessionBias（方案 C 每局微扰动）

- 开局 roll 出本局基调，对某一 Tag 维度整体轻微加/减：
  - 例「本局偏探索」→ 探索类 ×1.1、流派类 ×0.95；
  - 配额下限也做小幅随机偏移（如特殊卡下限本局 3、下局 4）。
- 幅度小，只制造**局间差异**，不破坏三目标保证。

## 6. 流派「成型线」判定（按现状，各罪不同）

用**现有机制卡的实际闭环**判定，不搞统一数字。拿满某条流派链的关键机制即视为「该流派成型」：

| 罪 | 成型判定（拿满关键机制即成型） | 约需机制卡数 |
|---|---|---:|
| 傲慢 | 位移剑气链（路径剑气 + 距离/穿梭 + 斩击形态） | ~4 |
| 怠惰 | 召唤链 或 重炮链任一条 | ~3 |
| 暴食 | 吞噬链（吞 → 过饱 → 兑现） | ~4 |
| 嫉妒 | 记录兑现链（4 张机制全拿） | 4 |
| 愤怒 | 低耐久身份 + 一条钩索机制 | ~4 |
| 贪婪 | 魔手增殖链 或 防御反击链任一条 | ~4 |
| 色欲 | 锚点体系（双锚点 + 2 个消费机制） | ~4 |

> 「成型」看**某条流派链关键机制是否集齐**，不是机械数总数——对玩家意味着玩法体验完整，而非数字达标。

**当前牌池短板 — 嫉妒：** 其机制卡仅 4 张且高度线性、无第二条构筑路线。在不补卡前提下，**定位为「轻量 / 入门流派」**，成型线即那 4 张机制全拿；规则不为它开特例，它成型快、可玩分支少是当前牌池的客观事实。

## 7. 分槽自动化程度（现有标记能力）

| 规则需要的判断 | 现有标记够吗 | 依据 |
|---|---|---|
| 归入横向 / 流派 / 探索 | ✅ 完全够，可全自动 | 真源「分类」字段 / ID 前缀 |
| 识别特殊卡（露面下限） | ✅ 完全够 | 「分类」= 全局槽位质变（`GX-`） |
| 废牌过滤 | ✅ 基本够 | `Stack Max` + 运行时零效果判定 |
| 机制卡 vs 数值卡 | ⚠️ 关键词可推断 ~85% | 「机制类别」字段，需人工校对灰色卡 |
| 机制卡属于哪个流派链 | ❌ 无现成标记 | 需人工新增 `buildLine` |

灰色卡示例（需人工点头）：`PR-M01`（突进距离，形式数值但喂给傲慢路径剑气流产生机制价值）、`WR-B01`（低耐久增益，形式叠层但是愤怒流派身份核心）。

## 8. 单卡刷新规则

- 每次商店，**每张卡独立拥有 1 次刷新**，互不共享。
- 刷新只重抽**该张**，**完全复用 §4 的 `Weight()`**，在点刷新瞬间按当前状态重算。
- 刷新专属排除：当前显示的这张 + 本次另两张的 ID。
- **刷新绝不写状态**：不消耗配额、不动投资 / 抑制 / 成型 / 露面计数——刷新只「换看什么牌」，不影响生态节奏。
- 池被排空的兜底：横向 → 借探索；流派 → 借同罪其他 → 借探索；探索 → 借任意合法；仍空则**保留原卡、不扣刷新次数**。
- 玩家一旦从任一位置选卡，本次商店立即结束，其余刷新作废（不可囤刷再挑）。

## 10. 影响因素总览（一句话）

> 每次抽到什么 = **本局随机基调（SessionBias）** × **当前还欠哪些配额（QuotaFactor）** × **流派成型到哪一步（BuildFactor）** × **玩家投资与近期抑制（Investment / Suppression）** × **卡本身的 Tag 与废牌过滤（HardMask）**。
>
> 其中「配额欠账 + 每局微扰动」负责让体验多变（逐次不可预测、局局有差异），「配额下限 + 成型进度」负责守住三个设计目标，一松一紧共同决定卡池选取。
