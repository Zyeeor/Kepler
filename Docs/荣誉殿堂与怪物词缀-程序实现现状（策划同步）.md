## 1. 荣誉殿堂：现在长什么样

### 1.1 一条记录记什么

**记录身份 = `玩家 + 该局 + 宗罪`**。一局里，只要你给某个宗罪的怪**投了至少 1 张卡**，就会留下一条记录；Run 结束后冻结。没投卡的临时附身怪不记录。

每条记录分**两段**展示，互不混用：

| 段落 | 内容 |
|------|------|
| **原始 Run 表现** | 保存时间、到达阶段、BD 深度（投了几张卡）、卡清单、本局控制时长、本局击杀数 |
| **异步战绩**（别人局里） | 被投放次数、被击杀次数、被附身次数、造成 Body Fatal 次数、导致 Run Fail 次数 |

异步战绩只有在联网拉取到时才有；没拉到会显示「未同步」，**不影响本地记录查看**（断网也能看）。

**长期保留**：记录永久保存，不会因为精英怪候选库满了被挤掉。

### 1.2 界面现在怎么排

```
◆ 暴食（4 卡构筑）（gluttony）  01-01 08:16  胜利 · 到达第 5 波
种类 暴食-魔猫
──── 原始 Run 表现 ────
BD 深度 4│控制 120 秒│本局击杀 7
GL-A03、GL-A02、GL-S03、GL-S02
──── 异步战绩（未同步）────
被投放 0│被击杀 0│被附身 0│致 Body Fatal 0│致 Run Fail 0
```

- **标题**现在是**词缀名**（见第 2 节），宗罪种类名降级到第二行「种类 XXX」
- 排序：点顶部按钮循环切换 `保存时间 / 击杀数 / 致 Run Fail 数 / BD 卡数`，**默认按保存时间倒序**
- 卡清单里存在已被删除的卡时，末尾会追加「（部分卡牌已失效 / 历史版本）」

### 1.3 从哪进

- **正式流程**：主菜单里有入口按钮
- **调试**：非正式流程下按 **F6** 直接开关，方便随时看数据

## 2. 怪物词缀：怪物现在有名字了

### 2.1 一句话

**你给怪投了哪些卡，决定了它叫什么名字。** 同一套卡永远得到同一个名字，不同卡组合得到不同名字。名字只是展示，**不给任何战斗加成**。

例：暴食投「远方圣餐 + 猎步圣餐 + 万物皆食 + 最后一餐」→ 名字里会出现 `远诱 / 阔口 / 贪噬 / 终食` 四个词。

### 2.2 名字怎么来的

每个卡配一个 2 字**明线词**（如「三重」）和一个**暗线词**（如「三实例」）。系统从你的卡清单里挑最多 4 个词，按固定顺序拼起来：

```
投 1 张卡 → 1 个词      投 3 张卡 → 3 个词
投 2 张卡 → 2 个词      投 4 张及以上 → 4 个词（上限）
```

选词时优先挑**描述不同侧面**的词，避免四个词都在说同一件事。

### 2.3 现在名字显示成什么样

⚠️ **当前显示的是「中立版」**：`暴食（4 卡构筑）`

完整形态要等 **First Clear 后三条文本线解锁**才会出现，届时同一只怪会有两套叫法：

| 显示线 | 样子 |
|--------|------|
| **Mythic**（神话线） | `远诱阔口贪噬终食之暴食` |
| **System**（系统线） | `Gluttony Carrier · 落点解锁/覆盖翻倍/全量吞噬/低耐久终止 · Rev.4` |
| Neutral（未解锁时） | `暴食（4 卡构筑）` |

解锁后玩家可手动切换 Mythic / System。**这不是 bug**，是需求规定的：First Clear 前默认 Mythic，之后默认 System（`Meta_Progression §4.7`）。

### 2.4 策划在哪里改词

菜单：**`Kepler > Cards > Epithet 词缀表`**

打开就能看到全部 49 张卡（已按宗罪分组），每行可直接改：明线词 / 暗线词 / 中性词 / 选轴 / 选槽 / 权重。

**已经预填了 49 个词**（来自设计文档附录 A），但状态是 `AGENT DRAFT`——**策划可以也应当逐词审阅替换**。

工具自带的功能：

| 按钮 | 作用 |
|------|------|
| 同步卡池 | 新加卡后点一下，自动出现在表里（不用手工录 ID） |
| 生成 | 输入几个卡 ID，即时预览这组合会叫什么名字（三套线都显示） |
| 校验 | 自动查出问题：词不是 2 个字、同宗罪里重复用字、跨宗罪撞词、用了品质词（传说/稀有/至尊等）、疑似暴露数值、哪些卡还没填词 |
| 保存 | 同时写入词缀表和文本表，**策划不用去动文本资产** |
| bump 版本 | 改完词表后点一下，老记录的名字会在下次打开殿堂时按新词表重算 |

改完词**不会影响**策划已经手工调整过的内容（工具只填空值，不覆盖已有内容）。

### 2.5 名字也用在局内

别人局里遇到你养过的怪时，横幅会显示这个名字——**你在自己殿堂里看到的名字，和别人打它时看到的是同一个**。

定时刷出的、没有历史构筑的精英怪**不加词缀**，仍用原来的种类名（不凭空编一个不存在的玩家）。

## 5. 常见问题

**Q：我改了一个词，老记录的名字会变吗？**
会，但需要**两步**：改词 → 点「bump 版本」。下次打开荣誉殿堂时，老记录会按新词表重算。这是故意设计的，方便修错别字。

已实测：把 `远诱` 改成 `远猎` 并 bump 后，老记录从「远诱阔口贪噬终食」变成了「远猎阔口贪噬终食」。

如果**只改词不 bump 版本**，老记录名字保持不变（名字已冻结）。这样万一改错了，不 bump 就不会影响已生成的记录。

**Q：某张卡被删了，记录里的名字会变吗？**
不会。名字一旦生成就冻结了（`epithetCache`）。卡被删只会在条目上追加「部分内容已失效」标记，名字保持原样。

**Q：同一个构筑打了两局，会有两条一模一样的名字吗？**
会，第二条起标题自动带 `· II`、`· III` 这样的世代标记，方便区分。

已实测：两条相同暴食构筑 → 第一条 `暴食（4 卡构筑）`，第二条 `暴食（4 卡构筑） · II`。**只有真正重名时才带标记**，单独的记录永远不带。

**Q：词缀会给怪加属性吗？**
不会。零 Gameplay 影响，纯展示（需求 `§5.1`）。名字长短也不会配色阶、星级——**避免被误读成品质等级**。
