# DEC-CANON-20260821-006 — 局外系统（卡牌图鉴 / 荣誉殿堂）与Elite数据链路

- **Date:** 2026-08-21
- **Owner status:** Approved
- **Source:** 《周边系统》Owner Source（荣誉殿堂 / 卡牌图鉴）

## Decision

当前Demo的局外界面系统收敛为**卡牌图鉴**与**荣誉殿堂**两个，二者只记录与展示、不提供战斗加成。Elite「他人构筑」投放属于核心玩法数据侧。UGC创作平台本期不开发。

## Added

- `Content/Meta_Progression_Systems_Baseline_v1.0.md`：定义两个局外界面、Elite数据链路与共享基础设施的行为、数据字段和验收；
- 卡牌图鉴三态可见性、Profile字段、通用卡独立页、双线显示、进度分母与版本兼容；
- 荣誉殿堂记录身份、长期保留、异步战绩字段与Elite战果回传依赖；
- Elite本地Preset兜底、标准化Build深度、`stack`恒1快照格式与版本兼容。
