# DEC-CANON-20260820-004 — 嫉妒卡牌裁剪与合并

- Date: 2026-08-20
- Owner status: Approved

## Decision

删除 EN-A04、EN-R04、EN-TG01；保留 EN-R01，并将 EN-R02 合并至 EN-R01。

## Removed cards

| Card ID | 名称 | 处理 |
|---|---|---|
| EN-A04 | 妒神凝视 | 删除 |
| EN-R04 | 凝视未终 | 删除 |
| EN-TG01 | 万妒远证 | 删除；嫉妒不再拥有 Type Growth |

## Merged card

- 保留 EN-R01｜无底之镜。
- 吸收 EN-R02｜伤痕告解 的 Mark 写入效率提升效果。
- 单层效果：Mark 储存伤害量提升 50%，并提高有效激光伤害写入目标 Mark 的效率。
- 写入效率的具体数值标记为 TUNABLE / PLAYABLE。
- EN-R02 不再作为独立 Card ID。

## Impact

- 嫉妒：10 张 → 6 张。
- 总牌池：69 张 → 65 张。
- Monster-Type + Type Growth：53 张 → 49 张。
- Type Growth：3 张 → 2 张，当前为 PR-TG01、LU-TG01。
- 嫉妒成为无 Type Growth 的 Owner 确认例外。
