# DEC-CANON-20260819-002 — Card Stack 机制废除

- **Date:** 2026-08-19
- **Owner status:** Approved
- **Decision:** 全牌池废除叠层（Stack）机制，`Stack Max` 统一为 1，卡牌唯一获取、不再支持重复叠加。

## Changed cards

原 6 张可叠层卡累计叠层效果合并进单层，`明线/暗线叠层后文本` 字段恒置空保留追溯：

| Card ID | 名称 | 原 Stack | 合并后单层口径 |
|---|---|---|---|
| `SL-A02` | 巨像之息 | 3 | 炮体取原 Stack 3 最终档位，尺寸 TUNABLE |
| `SL-S01` | 沉眠侍从 | 2 | 额外召两台木灵，数量 TUNABLE |
| `EN-A04` | 妒神凝视 | 2 | 激光窗口/转向取原 Stack 2 档，TUNABLE |
| `EN-R04` | 凝视未终 | 2 | 断连保留窗口取原 Stack 2 档，TUNABLE |
| `EN-S01` | 雷霆作证 | 2 | 命中 + 1s 复现 + 1s 第三次（共3次落雷），间隔/伤害 TUNABLE |
| `GR-A01` | 万手圣库 | 2 | 库存/释放上限取原 Stack 2 档，TUNABLE |

## Tunable

合并后的单层数值档位一律 `TUNABLE / PLAYABLE`，开发期公开可调；不再按叠层逐档递增。

## Superseded

无。此前叠层机制为 Card v1.1 既有规则，现废除；历史可叠层语义不再作为设计 Authority。

## Follow-up

- Offer 过滤「已达 Stack Max」随唯一获取语义简化为「Card 已取得」。
- 程序侧需将合并后的数值档位以 TUNABLE 参数开放调试。
