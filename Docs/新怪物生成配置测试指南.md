# 新怪物生成配置测试指南

面向策划与关卡配置人员，适用于正式测试场景 `EnemyAiTest`。

## 1. 先看开关

在场景的 `WaveManager` 上配置：

| 开关 | 结果 |
|---|---|
| `continuousSpawning = true` | 使用新逻辑：2 秒常规刷怪、每分钟怪潮、周期精英、7 分钟 Boss 前倒计时 |
| `continuousSpawning = false` | 使用原逻辑：原有 `CountKill` / `Timed` 波次、清场、选卡流程 |

有 `RoomTemplate` 接管的房间始终保留原有房间波次流程。

## 2. 新逻辑默认规则

默认罪印轮换顺序为：

```text
傲慢 → 怠惰 → 暴食 → 嫉妒 → 愤怒 → 贪婪 → 色欲 → 循环
```

| 时间 / 事件 | 规则 |
|---|---|
| 每 2 秒 | 生成 1 只普通怪，按上面的顺序轮换；该罪印只在玩家视角对应的七等分扇区内生成，位置在屏幕外、靠近屏幕边缘的随机合法位置 |
| 玩家击杀回响 | 生成同一种罪印的普通怪；复用该罪印扇区取点；立即生成；所有类型合计最多 2 只 / 2 秒窗口 |
| 每分钟第 30 秒 | 开始怪潮，持续 9 秒 |
| 怪潮每 3 秒 | 每种罪印生成 1 只，共 7 只；默认发生在第 30、33、36 秒 |
| 怪潮期间击杀回响 | 上限临时提升为所有类型合计最多 7 只 / 2 秒窗口；第 39 秒怪潮结束后恢复为 2 只 |
| 每分钟第 40 秒 | 生成 1 只精英怪；精英罪印按轮换顺序逐分钟变化 |
| 每 30 秒 | 新生成怪物使用新的数值成长档位；该成长先于同一时刻的怪潮注入 |
| 第 420 秒 | 7 分钟非 Boss 时间结束，进入 Boss 阶段；倒计时从 420 秒开始 |

普通怪、怪潮怪、击杀回响和精英共用 `MonsterSpawner.maxCombatMonsters` 全场上限。`EnemyAiTest` 当前配置为 `60`；若要完整观察首分钟的五次怪潮注入与 40 秒精英，不要把它调低到 60 以下。

## 3. WaveManager 可调参数

| 字段 | 默认值 | 作用 |
|---|---:|---|
| `normalSpawnInterval` | 2 | 常规刷怪间隔（秒） |
| `normalSpawnCountPerTick` | 1 | 每次常规刷怪数量 |
| `continuousSpawnOrder` | 七罪 | 常规刷怪、怪潮和精英的罪印顺序 |
| `spawnCycleSeconds` | 60 | 周期长度（秒） |
| `tideStartSeconds` | 30 | 周期开始后多久进入怪潮 |
| `tideDurationSeconds` | 9 | 怪潮持续时间（秒） |
| `tideSpawnInterval` | 3 | 怪潮注入间隔（秒） |
| `tideSpawnCountPerSin` | 1 | 怪潮每次每种罪印生成数量 |
| `eliteSpawnOffsetSeconds` | 40 | 周期开始后多久生成精英 |
| `eliteCountPerCycle` | 1 | 每周期精英数量 |
| `nonBossDurationSeconds` | 420 | Boss 前战斗时长（秒） |
| `difficultyGrowthIntervalSeconds` | 30 | 怪物数值成长周期（秒） |
| `killEchoMaxCountPerWindow` | 2 | 击杀回响窗口内全类型总上限 |
| `tideKillEchoMaxCountPerWindow` | 7 | 怪潮期间击杀回响窗口内全类型总上限 |
| `killEchoWindowSeconds` | 2 | 击杀回响上限刷新窗口（秒） |

`continuousSpawnOrder` 中的 Prefab 来自当前 `WaveManager.waves` 的怪物编队。要保证七种怪都能生成，七种正式普通怪 Prefab 都必须出现在有效波次的 `weightedTable` 中，并且 Prefab 能解析出正确的 `SinType`。

精英使用 `Resources/EliteMonsterCatalog.asset` 的七种映射；缺少 Catalog 条目时，该次精英不会生成。

### MonsterSpawner 可调参数

| 字段 | 默认值 | 作用 |
|---|---:|---|
| `spawnSectorOrder` | 七罪顺序 | 玩家正前方为第 1 扇区，按列表顺序顺时针分配七个等分扇区 |
| `screenEdgeSpawnOffset` | 2 米 | 在屏幕外最近边缘距离上随机增加的最大距离；0 表示贴近最近边缘 |
| `killEchoScreenPadding` | 0.75 米 | 屏幕边界外的基础安全距离，普通怪、怪潮、精英和击杀回响共用 |

每种罪印的实际刷怪角度为其扇区内随机角度；距离为“屏幕外最近边缘 + `killEchoScreenPadding`”到该距离再加 `screenEdgeSpawnOffset` 之间随机。

## 4. 测试步骤

### A. 新逻辑基础测试

1. 打开 `EnemyAiTest`，确认 `WaveManager.continuousSpawning` 开启。
2. Play 后观察 2、4、6、8 秒附近的刷怪日志。
3. 检查怪物类型是否按七罪顺序轮换，而不是一直重复同一种。
4. 以镜头正前方为基准，将视角旋转到七个方向，确认每种罪印只在自己的扇区内生成。
5. 从 Game 视图确认怪物初始位置不在屏幕内，并且靠近屏幕边缘；调整 `screenEdgeSpawnOffset` 后，距离浮动范围应随之变化。
6. 让玩家处于附身状态，连续击杀普通怪，确认回响类型与被击杀怪相同，且仍落在该罪印扇区。
7. 在 2 秒窗口内连续触发多次击杀，确认回响最多成功生成 2 只；窗口刷新后可以再次生成。

### B. 怪潮与精英测试

1. 将游戏时间推进到 30 秒，确认怪潮开始。
2. 在 30、33、36 秒分别检查是否尝试生成七种怪各 1 只。
3. 确认怪潮所有取点都复用玩家周围环形、屏幕外边缘和可走 Tile 约束。
4. 在 40 秒确认生成 1 只精英；记录其罪印类型。
5. 继续测试到 100、160、220、280、340、400 秒，确认精英罪印按轮换顺序变化，七个周期内不重复。
6. 在 30 秒边界前后对比新生成怪物数值，确认 30 秒成长档位先于 30 秒怪潮生效。
7. 在怪潮期间连续触发击杀，确认回响上限为 7；怪潮结束后恢复为 2。

### C. 7 分钟与旧逻辑回归

1. 确认倒计时从 `7:00` 开始，并在 420 秒归零。
2. 确认 420 秒前不会提前进入 Boss 阶段。
3. 关闭 `continuousSpawning` 后重新 Play：不应出现“新逻辑常规刷怪 / 怪潮 / 精英”日志，应恢复原波次、清场和选卡流程。
4. 在 `EnemyAIAttackTestSpawner` 保持关闭的情况下完成以上测试，避免旧测试刷怪器重复注入。

## 5. 常见问题

| 现象 | 优先检查 |
|---|---|
| 某种罪印不生成 | 有效 `WaveManager.waves` 是否包含该 Prefab；Prefab 的 `MonsterActor.sinType` 或命名是否正确 |
| 只生成少量怪 | `MonsterSpawner.maxCombatMonsters` 是否已满；地图 Chunk / 可走 Tile / 屏幕外边缘是否有合法位置 |
| 怪物出现在屏幕内 | 检查主摄像机是否为运行时实际使用的 Camera，以及 `MonsterSpawner` 是否已成功取到该 Camera |
| 精英不出现 | 检查 `EliteMonsterCatalog.asset` 是否存在七种条目、Prefab 是否有效、全场怪物上限是否已满 |
| 关闭开关仍有旧逻辑以外的刷怪 | 检查是否还有其他系统显式调用 `RunSpawnDirector` 或场景中存在重复 WaveManager |

## 6. 验收重点

- 新旧逻辑可以通过 `WaveManager.continuousSpawning` 独立切换。
- 新逻辑默认节奏为：2 秒 1 只、30 秒开始 9 秒怪潮（每 3 秒一次）、40 秒精英、420 秒 Boss 前结束。
- 普通怪、怪潮和精英类型可辨识，七罪轮换不被单一类型锁死。
- 七种罪印分别锁定玩家视角七等分扇区，角度和屏幕外距离在对应范围内随机。
- 所有周期怪都从屏幕外边缘合法位置进入，不在玩家可见范围内凭空出现。
- 击杀回响按“所有类型合计”限制为 2 / 2 秒窗口。
- 怪潮期间击杀回响上限临时提升为 7 / 2 秒窗口，结束后恢复为 2。
- 调整时间或数量字段后，测试结果应随 Inspector 配置变化，不需要修改代码。
