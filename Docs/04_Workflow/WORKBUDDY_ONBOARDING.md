# WorkBuddy Onboarding

For a normal team member:

```text
Update Project
→ Look at Task
→ Claim Task
→ Move to Doing
→ Ask WorkBuddy to read the Task ID
→ Work
→ Self Check
→ Review
→ Done
```

Before the first Task, read `AGENTS.md`, `.vibe/rules.md`, this file, and the relevant Task. Work on a Task branch, not directly on `main`. Ask the Agent to report scope, files, plan, tests, risks, conflicts, and Shared Original impact before editing.

New members do not need rebase, cherry-pick, reflog, worktree, CI internals, or advanced merge knowledge on day one. Escalate conflicts and high-risk shared-asset work to the Professional Owner.
