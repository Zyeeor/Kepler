# 怪物技能释放预测配置指南

本文面向策划，说明 AI 怪物释放技能前的引导与技能框 HUD 配置方式。

## 1. 功能规则

AI 怪物决定释放技能后，会先进入引导阶段：

- 引导期间怪物不能移动，也不能释放其他技能。
- 怪物被玩家附身后释放技能，不进入 AI 引导，不显示该 HUD。
- 引导开始时，怪物旁边显示一个技能框，图标自动读取当前怪物和技能槽位的配置。
- 技能框初始为全灰，随着引导进度从灰色恢复到技能的可用颜色；引导完成后立即隐藏。
- 怪物在屏幕外或位于镜头背面时，技能框自动隐藏；怪物回到画面内后会继续跟随。
- 范围技能仍可同时显示地面命中范围指示圈。指示圈是范围提示，技能框是释放时机提示，两者职责不同。

引导阶段由 `EnemyAbility` 统一管理。激光、蓄力炮等从自身 `Update` 开始释放的技能也会接入同一套引导，不会绕过技能框。

## 2. 在哪里配置

配置入口是怪物 Prefab 上的具体 `EnemyAbility_*` 组件，不需要在场景中手工创建 HUD，也不需要修改 `UICanvas`。

选中技能组件后，在 Inspector 找到以下两个分组：

### 2.1 Enemy Cast Telegraph

| 字段 | 默认值 | 作用 |
|---|---:|---|
| `enemyTelegraphEnabled` | 开 | 是否启用 AI 引导。关闭后该技能直接释放，不显示预测 HUD。正式战斗技能通常保持开启。 |
| `enemyCastLeadTime` | `0.45` 秒 | 从 AI 做出释放决定到技能真正生效的时间。引导越长，玩家反应时间越充足。`0` 等同于关闭引导。 |

### 2.2 Enemy Cast HUD

| 字段 | 默认值 | 作用 |
|---|---:|---|
| `enemyCastHudSize` | `64` | 技能框边长。使用和左下角技能 HUD 相同的 Canvas 参考单位，四边等比缩放，形状固定。 |
| `enemyCastHudScreenOffset` | `(48, 44)` | 相对怪物屏幕投影中心的偏移。`X` 正值向右，`Y` 正值向上。单位同上，不是世界坐标。 |

坐标以当前 UI Canvas 的参考分辨率为基准（项目默认 `1920 × 1080`），CanvasScaler 会负责适配不同分辨率。不要把怪物的世界坐标、米数或 3D 偏移填入这个字段。

## 3. 技能图标配置

技能框会复用左下角 `AbilityCooldownUI` 的技能框层级，因此边框、灰色冷却遮罩和尺寸比例与玩家 HUD 一致。

图标来源：

```text
Assets/Resources/UI/MonsterSkillIconConfig.asset
```

在该资产的 `monsterEntries` 中，按以下组合配置图标：

| 怪物技能类型 | 对应配置槽位 |
|---|---|
| `BasicAttack` | `BasicAttack` |
| `Skill` | `Skill` |
| `Mobility` | `Mobility` |

运行时先按怪物的 `SinType + 槽位` 查找图标和颜色。暴食处于复制技能状态时，会优先使用被复制技能所属罪类型的技能图标。若找不到槽位图标，系统会尝试使用左下角 HUD 当前图标，再找不到时使用怪物身份图标；正式内容应为每个怪物三槽配置完整图标。

`iconColor` 是引导完成时的恢复颜色。引导开始时系统会统一压暗为灰色，避免玩家把“正在引导”误认为“已经可以释放”。

## 4. 范围技能指示圈

范围指示圈与技能框同时工作，仍由技能组件的 `Enemy Cast Telegraph` 字段控制：

| 字段 | 作用 |
|---|---|
| `enemyIndicatorEnabled` | 是否显示范围指示圈。非范围技能可关闭。 |
| `enemyIndicatorRadius` | 通用默认半径。部分范围技能会在代码中使用自身真实伤害半径覆盖该值。 |
| `enemyIndicatorColor` | 指示圈颜色。 |
| `enemyIndicatorIntensity` | 指示圈亮度。 |
| `enemyIndicatorHeight` | 指示圈离地高度。 |
| `enemyIndicatorOffset` | 通用指示圈相对怪物的局部偏移。 |

范围指示圈的亮度和内部动画会随引导进度变化。对于有明确落点的技能（例如地面砸击、暴食巨口），指示圈位置由技能自身的目标和落点逻辑决定；不要仅靠通用偏移模拟远程落点。

## 5. 推荐调参流程

1. 先确认技能的 `type`、技能图标和 `iconColor` 正确。
2. 打开 `enemyTelegraphEnabled`，从 `enemyCastLeadTime = 0.45` 开始测试。
3. 在游戏视图中确认技能框位于怪物侧上方，不遮挡怪物模型和主要受击区域。
4. 调整 `enemyCastHudSize`：小型怪物可从 `48 ~ 60` 起步，大型怪物可从 `64 ~ 80` 起步。
5. 调整 `enemyCastHudScreenOffset`：通常先调 `X`，让框位于怪物侧边，再调 `Y`，让框位于模型上方。
6. 范围技能再检查指示圈的颜色、半径和落点是否与实际伤害一致。
7. 最后从玩家视角确认：引导开始、引导进行中、引导完成、怪物被击倒/被附身四个时机都能正确显示和隐藏。

建议起步值仅用于 Playable 调校，不是冻结数值：

| 技能危险度 | 建议引导时间 |
|---|---:|
| 高频轻攻击 | `0.25 ~ 0.40` 秒 |
| 普通技能 | `0.40 ~ 0.60` 秒 |
| 大范围或高伤害技能 | `0.70 ~ 1.00` 秒 |

引导时间应和技能实际命中时间一致。技能自身已有的命中前摇不应被重复计算成两段完全相同的等待；如果技能内部还有额外延迟，应在实机中确认玩家仍能清楚区分“开始引导”和“真正命中”。

## 6. 验收清单

- [ ] AI 做出释放决定后，技能框立即出现。
- [ ] 技能框图标与怪物当前释放的槽位一致。
- [ ] 技能框初始为灰色，随后连续恢复到配置颜色。
- [ ] 引导期间怪物不移动，其他技能不能插入释放。
- [ ] 引导结束时技能按原逻辑释放，技能框立即隐藏。
- [ ] 玩家附身怪物释放同一技能时不显示引导 HUD。
- [ ] 怪物被击倒、被附身或技能禁用时，技能框不会残留。
- [ ] 范围技能的地面圈与实际命中范围、目标/落点一致。
- [ ] 怪物离开画面后 HUD 隐藏，回到画面后仍能正常跟随。
- [ ] 不同分辨率下，HUD 大小和偏移仍符合预期。

## 7. 常见问题

**Q：技能框没有出现怎么办？**

**A：** 检查 `enemyTelegraphEnabled` 是否开启、`enemyCastLeadTime` 是否大于 `0`，并确认场景中存在现有 `UICanvas` 和 `AbilityCooldownUI`。当前正式战斗场景已经具备这些 UI 条件。

**Q：技能框图标是空的怎么办？**

**A：** 检查 `MonsterSkillIconConfig.asset` 是否存在对应 `SinType + 槽位` 的 `monsterEntries`，并确认 `icon` 已拖入 Sprite。

**Q：为什么颜色不是纯白？**

**A：** 技能框完成时恢复的是 `MonsterSkillIconConfig` 中该条目的 `iconColor`，不是强制白色。需要白色时把该条目的颜色设为白色。

**Q：为什么范围技能有两个提示？**

**A：** 技能框表示“什么时候释放”，地面圈表示“哪里会命中”。高危险范围技能建议同时保留，非范围技能关闭 `enemyIndicatorEnabled` 即可。
