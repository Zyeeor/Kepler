# 统一文本与字体管理方案

> 日期：2026-08-24 | 状态：v1 已实现
> 设计真源：`.vibe/doc/Canonical/Content/Dual_Line_Text_Requirements_v1.0.md`（双线文本：Text Key 稳定、不在 Gameplay 代码写死最终词汇）

---

## 一、要解决的问题

| 问题 | 现状 |
|---|---|
| 文本散落 | CardData 卡名/描述、TutorialStepConfig 内联中文、12 个 UI 脚本硬编码 `.text=`、场景 24 处 TMP 默认文本 |
| 无法统一查看 | 无集中清单，改文案需逐处找 |
| 换字体困难 | 场景 28 处 TMP 各自绑 FontAsset，逐个改 |

## 二、方案架构

```
┌─ TextCatalog（文本目录 SO）───────────────┐
│  Assets/Resources/Text/TextCatalog.asset   │
│  entries: [{ key, text, mythicText, systemText }]  │
│  代码取文本：TextCatalog.Get("ui.pause.resume")     │
└────────────────────────────────────────────┘
┌─ FontRegistry（字体注册表 SO）─────────────┐
│  Assets/Resources/Text/FontRegistry.asset   │
│  slots: [{ slotName: default/title/number, font }] │
│  运行时：FontApplier 场景加载后自动套用      │
│  设计期：菜单一键替换（ApplyAllToActiveScene）│
└────────────────────────────────────────────┘
```

## 三、使用方式

### 1. 查看 / 管理所有文本
- 菜单 **Tools → Kepler → Text Catalog Viewer**
- 搜索过滤、上下移动、删除、添加条目
- 点击 **导出 CSV** 一键导出（key/text/mythic/system）供策划审阅

### 2. 统一更换字体
- 打开 `Assets/Resources/Text/FontRegistry.asset`，在 Inspector 把各槽字体换成新 SDF 字体资产
- 运行时：`GameManager.Start` 自动挂载 `FontApplier`（DDOL 常驻），每个场景加载后自动把场景内全部 TMP 文本套用注册表字体
- 设计期：右键 FontRegistry 资产 → `Apply All To Active Scene`（或菜单工具），不进入 Play 也能一键替换

#### 卡片字体统一配置（重点：改一处全部卡片生效）
1. 打开 `Assets/Resources/Text/FontRegistry.asset`；
2. 把含中文字形的 SDF 字体资产（如 BeiBanChuanSuiXinTi）拖到 **card 槽**（没有就点 slots 的 + 加一条，slotName 填 `card`）；
3. 完成。**选卡界面卡片（CoreChoiceUI）与 Debug 卡面浏览器（CardFaceBrowser，F3）的卡名/描述都会在实例化时自动套用 card 槽字体**——改这一处，全部卡片字体统一变。

原理：`CoreChoiceUI.RefreshCards` / `CardFaceBrowser.EnsurePreviewCard` 在 `Instantiate(cardPrefab)` 后调用
`FontRegistry.Instance.ApplyFontToTree(go.transform, FontSlots.Card)`（含 inactive 子节点），覆盖卡片模板上的默认字体绑定。

> 已知问题：卡片模板默认字体 rocky-rockin-2 **无中文字形**，CardLibrary 中的中文描述会显示为方块 □（Console 警告
> "character ... not found in font asset [rocky-rockin-2 SDF] ... text object [description]"）。配置 card 槽为中文字体后即解决。

#### 卡片文本配置决策（2026-08-24 Owner 意见）
- **卡片文本（卡名/描述）以 `CardLibrary.asset` 为唯一配置点**——在 CardData 的 `cardName` / `description` 字段直接配中文；
- CardData 上的 `textKey` 字段为**可选覆盖**（默认留空）：留空 = 纯 CardLibrary 配置；填了才走 TextCatalog（供后续本地化/双线场景使用）；
- 卡片字体走 FontRegistry 统一（见上）。

### 3. 代码取文本（替代硬编码）
```csharp
// 旧：buttonText.text = "继续";
// 新：
buttonText.text = TextCatalog.Get("ui.pause.resume");   // 静态入口
// 或带占位符：
TextCatalog.Get("ui.wave.title", waveIndex);            // "第 {0} 波"
```

### 4. 动态建字组件取字体（替代 UiFontAssets.Chinese 直接注入）
```csharp
var font = FontRegistry.Instance != null
    ? FontRegistry.Instance.GetFont(FontSlots.Default)
    : TMP_Settings.defaultFontAsset;
```
（旧静态点 `UiFontAssets.ChineseOrDefault` 保留兼容，内部已回退 FontRegistry）

### 5. 存量数据接入（已完成）
- **TutorialStepConfig**：`textKey` 已启用——配置 `textKey = "tut.01"` 后，标题取目录 `tut.01.title`、正文取 `tut.01.body`；未配置时回退内联 title/text（老数据无感）
- **CardData**：新增 `textKey` 字段——配置 `textKey = "card.slash"` 后，卡名取 `card.slash.name`、描述取 `card.slash.desc`；未配置回退 cardName/description

```
final.*       终局
elite.*       精英
```
