## 1. 怪物双套数值（Enemy / Possessed）

### 配置位置

怪物 Prefab 根上的 `MonsterActor` / `Enemy`：

- **Dual Stats (Enemy vs Possessed)**
  - `Enemy Stats`：AI 敌方态
  - `Possessed Stats`：玩家附身态
- 字段：`maxHealth` / `moveSpeed` / `acceleration` / `deceleration` / `maxTenacity` / `collisionDamage` / `attackSpeed`

### 生效时机

| 时机 | 使用哪套 |
|---|---|
| 刷怪 / `ResetForSpawn` | Enemy Stats |
| `OnPossessed` | Possessed Stats（满血满韧性刷新） |

旧 Prefab 若两套为空，会把当前运行时字段自动拷进两套（默认相同，请再分开调）。

### 测试

1. 把某怪 `Enemy Stats.maxHealth=100`，`Possessed Stats.maxHealth=200`
2. 刷成敌人 → 血条上限 100
3. 击杀掉落尸体后附身 → 血量上限变为 200

## 2. 材质表现（高亮 / 溶解 / 受击闪）

### 原则

- **常规态不改 Shader、不整模染色**
- 组件：`ActorVisualFx`（怪物 Prefab / 灵魂已挂）
- 模板材质：`Assets/Shaders/M_PossessionCharacterFX.mat`（仅尸体溶解阶段临时使用）

### Inspector 可调

| 字段 | 含义 | 建议 |
|---|---|---|
| Possession Rim Color / Intensity | 附身高亮 | Intensity 1.5–2.5 |
| Hit Flash Color / Duration / Peak | 受击闪 | Duration ≈ 0.12 |
| Fx Material Template | 溶解用模板 | 保持 `M_PossessionCharacterFX` |

### 测试

1. Play → 怪与灵魂应为正常贴图光照  
2. 附身 → 仅边缘/自发光高亮  
3. 攻击 → 目标闪一下  
4. 击杀 → 尸体站立一段时间后溶解消失  

若仍看到黑影/紫模：停掉 Play 再进（清掉旧局残留材质实例）。

## 3. 地形 Trigger Tile

ChunkDef `triggerTiles` 已配置：

| Prefab | Kind | 参数要点 |
|---|---|---|
| `SpikeTrap` | Spike | Enter 伤害（默认 25）；站立不重复 |
| `Brick (diamond) 1` | SpeedBoost | 移速 ×1.5；离开恢复 |
| `lava1` | Lava | Effect=`Effect_Terrain_LavaBurn`；VFX=`burn`；0.5s 叠层，最高 5，持续 3s |

### 组件

挂在 Tile Prefab 根上：

- `TileVisual`：`terrainKind = Trigger`，`isWalkable = true`
- `TerrainEffectTile`：Kind / Effect / 伤害与叠层参数
- **Trigger Collider**（缺会自动补 BoxCollider）

### 岩浆 Effect 资产

`Assets/Combat/Effects/Effect_Terrain_LavaBurn.asset`

- `duration=3`，`maxStacks=5`，`stackPolicy=AddStack`
- `periodicInterval=0.5`，`damagePerStack=5`
- `activeVfxPrefab` → `Assets/Prefabs/VFX/Prefabs/burn.prefab`

### 检测实现说明

角色用 `transform` 移动且通常**无 Rigidbody**，因此不用 `OnTriggerEnter`。  
`TerrainEffectTile` 在 `FixedUpdate` 里用 `Physics.OverlapBox` 扫描占用；检测盒默认约 `1.4 × 2.5 × 1.4`（本地），中心 `(0,1,0)`。

### 测试

1. 走 Spike：踩上掉血，停在刺上不再掉  
2. 走加速砖：移速变快，离开恢复  
3. 走岩浆：身上出现火焰 VFX，持续掉血；离开后最多再烧约 3s；多待会叠层（伤害升高）

> 当前 ChunkDef 无单独减速 Tile。若要减速：复制一块 Trigger Prefab，`TerrainEffectTile.kind=Slow`，`moveSpeedMultiplier=0.5`，并加入 `triggerTiles`。

## 5. 已知：作弊附身与「打怪不掉血」

### 原因（已修）

`Monster Possession Cheat`（数字键 1–9 刷怪并附身）会给**当前作弊身体**挂永久 `Effect.Defense.DamageImmune`。

旧逻辑在换下一个作弊身体时，**没有清掉上一具的免疫**，上一具留在场上变成「打不死的普通怪」。

### 修复后行为

- 换作弊身体：上一具清除免疫，并按开关回收  
- 退附身 / 回池：清除 `DamageImmune`  
- **当前**作弊附身自身仍可免疫（Inspector：`Immortal Cheat Bodies`）

### QA 注意

| 操作 | 期望 |
|---|---|
| 打**自己**作弊附身 | 可不掉血（若 Immortal 开着） |
| 打**其他敌人** | 必须掉血 |
| 关 `Immortal Cheat Bodies` | 自身也被打掉血 |
| 正式流程 `GameManager.IsFormalFlow` | 作弊面板关闭 |

若局内已残留旧免疫怪：停 Play 再开，或打 Console 搜 `DamageImmune`。
