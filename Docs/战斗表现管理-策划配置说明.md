# 战斗表现管理 — 策划配置说明

面向策划的命中反馈（后处理 / 震屏 / 顿帧）配置手册。  
程序入口：技能组件上的 **Hit Feedback**；运行时由 `CombatEffectManager` 统一播放。

---

## 1. 这套系统做什么

技能**第一次造成伤害**时，可同时触发：

| 效果 | 作用 |
|------|------|
| 后处理 | 切换场景里 Panda 后期效果（短时冲击感） |
| 震屏 | 镜头抖动 |
| 顿帧 | 短暂放慢动画（默认不影响战斗逻辑） |

同一技能一次攻击内，无论打中几个目标，**只播一次**反馈。

---

## 2. 在哪里配置

### 2.1 技能侧（主要）

1. 打开角色 / 怪物 Prefab，或场景中的技能物体  
2. 选中具体技能脚本（如砍击、子弹、怪物 Skill）  
3. Inspector 找到 **Hit Feedback (Combat Effect Manager)**  
4. 按下方字段表填写  

适用对象：

- **Soul 技能**（`PlayerAbility`）：玩家灵魂形态攻击 → 按配置播放  
- **怪物技能**（`EnemyAbility`）：**仅玩家附身操控该怪时**播放；AI 自己打人不会播，避免镜头乱抖  

### 2.2 全局默认值（次要）

有 `CameraDirector` 的场景会自动挂 `CombatEffectManager`（一般在主相机上）。

在相机上的 `CombatEffectManager` 可调：

| 字段 | 默认 | 含义 |
|------|------|------|
| Default Shake Force | `1` | 技能震屏力度填 `0` 时用这个 |
| Default Hit Stop Duration | `0.07` | 技能顿帧时长填 `0` 时用这个（秒） |
| Default Post Process Duration | `0.15` | 技能后处理时长填 `0` 时用这个（秒） |
| Post Process Switcher | 可空 | 空则自动找场景里的 `PandaPostProcessSwitcher` |

**约定：技能里数值填 `0` = 使用上表全局默认，不是“关闭”。**  
关闭某效果请关掉对应开关（见下节）。

---

## 3. 字段说明（Hit Feedback）

### 3.1 后处理 Post Process (Panda)

| Inspector 名称 | 默认 | 策划怎么用 |
|----------------|------|------------|
| Post Process On Hit | 关 | 勾选后才会播后处理 |
| Post Process Effect Name | 空 | **必填**效果名，需与场景 Panda 切换器里某条一致（优先填**材质球名字**） |
| Post Process Duration | `0` | 持续秒数；`0` → 用全局默认 `0.15` |
| Override Post Process Params | 关 | 勾选后，下面一排数值会临时覆盖该效果参数，结束自动还原 |
| Step Factor | `0.5` | 像素剔除程度（需开 Override） |
| Main Alpha | `1` | 总透明度 |
| Blur Factor | `0` | 径向模糊 |
| Line UV Scale | `0` | UV 拉伸 |
| Chromatic | `0` | 色散 |
| Frequency / Amplitude | `0` | 振频 / 振幅（后期里的“震屏”感，不是镜头震屏） |
| Vignette Power / Scale | `1.5` | 黑边宽度 / 强度 |

注意：

- 只开开关、**不填效果名** → 后处理不会播  
- 效果名填错 → Console 会有警告，游戏不崩  
- 当前只接 **Panda 后期**；URP Global Volume 尚未接入  

### 3.2 震屏 Screen Shake

| Inspector 名称 | 默认 | 策划怎么用 |
|----------------|------|------------|
| Shake On Hit | 开* | 关 = 不震屏 |
| Shake Force | `0` | 力度；`0` → 全局默认 `1`。建议从 `0.5 ~ 2` 试 |
| Shake Duration | `0` | 抖动时长（秒）；`0` → 用相机 Impulse 现有默认，一般不用改 |

\* Soul 技能脚本代码默认多为关；具体 Prefab 以 Inspector 实际勾选为准（例如 Player 砍击可能已开）。

### 3.3 顿帧 Hit Stop

| Inspector 名称 | 默认 | 策划怎么用 |
|----------------|------|------------|
| Hit Stop On Hit | 开* | 关 = 不顿帧 |
| Hit Stop Duration | `0` | 持续秒数；`0` → 全局默认 `0.07`。高频普攻建议 `0.03 ~ 0.08`，重击可到 `0.1 ~ 0.15` |
| Hit Stop Scale | `0` | 动画播放倍率：`0` = 完全定格，`0.2` = 慢放。一般用 `0` |
| Use Global Time Scale | 关 | **默认关。** 关 = 只放慢 Animator，逻辑 / 子弹时间正常；勾选 = 额外改全局时间（旧方案，易和子弹时间冲突，慎用） |

\* 同上，以 Prefab 实际值为准。

## 4. 推荐调参流程

1. **先只开震屏**：确认命中有反馈，再调 `Shake Force`  
2. **再加顿帧**：从 `Hit Stop Duration = 0.05`、`Scale = 0` 起，体感过重就减时长  
3. **最后加后处理**：填好 Effect Name，时长约 `0.1 ~ 0.2`；需要特殊色散/模糊再开 Override  
4. 同一角色多个技能：轻攻击弱反馈、重攻击强反馈，避免每一下都全开满数值  

Canonical 提醒：不要用过量顿帧破坏高频动作手感。

---

## 5. 常见配置示例

### 轻攻击（灵魂砍击）

```text
Post Process On Hit = 关
Shake On Hit = 开，Force = 0.8，Duration = 0
Hit Stop On Hit = 开，Duration = 0.05，Scale = 0
Use Global Time Scale = 关
```

### 重击 / 大招

```text
Post Process On Hit = 开，Effect Name = （填美术提供的材质名），Duration = 0.15
Override = 按需
Shake On Hit = 开，Force = 1.5
Hit Stop On Hit = 开，Duration = 0.1，Scale = 0
```

### 完全不要命中反馈

```text
Post Process On Hit = 关
Shake On Hit = 关
Hit Stop On Hit = 关
```

## 6. 场景前置条件（找程序 / 关卡确认即可）

| 需求 | 需要有什么 |
|------|------------|
| 震屏 / 顿帧 | 场景有带 `CameraDirector` 的主相机（一般已有） |
| 后处理 | 场景有 `PandaPostProcessSwitcher`，且上面挂了若干 `PandaPostProcess`；效果名与材质名对齐 |

策划通常只需改技能 Prefab；后处理列表由美术在场景里维护，策划向美术要「可用效果名清单」。

## 7. FAQ

**Q：填了震屏力度 0，为什么还会抖？**  
A：`0` 表示「用全局默认力度」，不是关闭。关闭请取消勾选 `Shake On Hit`。

**Q：为什么怪物 AI 打我不震屏？**  
A：设计如此。只有**玩家附身该怪物**时，该怪物技能的 Hit Feedback 才会播。

**Q：一次 AOE 打中 5 个会震 5 次吗？**  
A：不会。同一次技能释放只播一次。

**Q：顿帧会不会让技能 CD / 子弹变慢？**  
A：默认不会（只改动画速度）。只有勾了 `Use Global Time Scale` 才可能影响全局时间。

**Q：后处理播完镜头花了？**  
A：应会自动还原。若仍异常，检查是否有多个 Switcher，或效果名匹配到了错误条目。
