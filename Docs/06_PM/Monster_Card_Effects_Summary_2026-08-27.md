# 《Possession》怪物卡牌效果总表

> **版本：** 2026-08-27 汇总版  
> **依据：** `02_CONTENT_CANONICAL.md` + `Content/Card_System_Current_Truth_v1.1.md`  
> **范围：** 当前 7 只普通可附身怪物的 Monster-Type / Type Growth 卡，共 **49 张**。不含 9 张基础通用卡与 7 张全局槽位质变卡。

## 使用规则速览

- **Monster-Type Card：** 作用于对应类型的普通 Enemy 与对应的普通 Possessed Body。
- **Type Growth：** 取得后也令对应罪的 `Investment +1`；当前仅傲慢与色欲各有 1 张。
- **Elite 例外：** Elite 无论敌人态或被附身后，均不读取本 Run 的 Monster-Type / Type Growth 卡，而只保留自己的 Historical Build Snapshot。
- **数值状态：** 除明确写明的数值外，“提高 / 扩大 / 更快 / 更久”等具体档位仍为 `TUNABLE / PLAYABLE`。
- **已删除卡：** 不列入本文；不得为了覆盖率恢复历史删除卡。
