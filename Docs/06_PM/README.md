# Production Management Inputs

A formal PM plan may be generated only when these inputs exist:

```text
Production Draft Central Design
+ Canonical
+ Open Decisions
+ Legacy Audit
+ Current Unity Project State
+ Team Capacity
+ Available Time
+ Workflow Rules
```

Current planning constraints:

- Art: 2 weeks
- Client Engineering: 3 weeks
- Design: 4 weeks

Professional Owners must calibrate estimates. Agents may split Features and Tasks, map dependencies and the critical path, identify capacity risks, and propose scope cuts or cross-role support. Agents must not determine final schedules unilaterally.
