# 罪印动效配置指南

## 1. 功能概述

玩家成功附身一个怪物后，怪物对应的罪印层数会进入一次“罪印回收”表现：

1. 一颗带有发光核心和动态拖尾的流星从怪物身体位置飞向左下角对应罪印图标。
2. 流星抵达图标后，罪印数量才会增加，避免数字先跳变再播放表现。
3. 实际玩法层数在附身提交时已经生效，因此附身后的属性、冷却与伤害不会被表现动画延迟。
4. 如果 HUD 或目标图标不可用，系统会跳过表现并立即刷新数量，保证玩法状态不被 UI 阻塞。

流星使用 `Assets/Resources/MonsterTelegraph/PossessionImprintMeteor.shader`，材质在运行时创建，不需要在场景里额外摆放粒子预制体。

## 2. 配置入口

在每个怪物 Prefab 上选中挂载 `ActorVisualFx` 的对象，在 Inspector 的 **Possession Imprint Meteor** 区域配置。`PossessionImprintHUD` 只负责播放当前附身怪物提供的参数，不再持有一套全局流星配置。

| 参数 | 默认值 | 说明 |
|---|---:|---|
| `Possession Imprint Meteor Speed` | `1200` | 飞行速度，单位为 Canvas 像素/秒。数值越大，飞行越快。建议范围 `700–1800`。 |
| `Possession Imprint Meteor Width` | `42` | 流星主体与拖尾高度，单位为 Canvas 像素。建议范围 `28–64`。 |
| `Possession Imprint Meteor Tail Length` | `0.34` | 拖尾长度占起点到终点路径的比例。建议范围 `0.20–0.50`。 |
| `Possession Imprint Meteor Glow` | `1.8` | Shader 发光强度。建议范围 `1.2–3.0`；过高会造成 UI 过曝。 |
| `Possession Imprint Meteor Color` | 青蓝色 | 流星颜色，支持 HDR。每个怪物可独立配置。 |
| `Possession Imprint Meteor Shader` | 留空 | 每个怪物可指定替代 Shader；留空时从 `Resources/MonsterTelegraph/PossessionImprintMeteor` 加载。 |

### 推荐配色

- 通用罪印回收：青蓝 `#40D9FF`，体现灵魂能量被 UI 吸收。
- 强调愤怒 / 狂暴：橙红 `#FF5B35`。
- 强调嫉妒 / 雷电：紫青 `#B77CFF`。
- 强调怠惰 / 机械：冷青 `#75F2E5`。

## 3. 设计与时序规则

- 目标图标由 `PossessionImprintHUD.icons` 的固定七罪顺序决定：傲慢、愤怒、暴食、贪婪、嫉妒、色欲、怠惰。
- 起点取附身体的世界坐标并投影到 HUD；终点取对应 `PossessionImprintIcon` 的中心，因此不应在代码中写死屏幕坐标。
- 罪印图标数量由“已显示层数”驱动，只在流星的抵达回调执行后刷新。
- 罪印的实际数值仍由 `PossessionImprintManager.GetStacks` 提供；策划不应把动效延迟理解为属性生效延迟。
- 多次连续附身会分别创建飞行表现，并按各自的抵达时刻更新图标。

## 4. 调参建议

1. 先固定 `Possession Imprint Meteor Color`，再调整 `Possession Imprint Meteor Speed`，避免同时改变速度和色彩导致节奏判断失真。
2. 低分辨率或 UI 缩放较小时，优先降低 `Possession Imprint Meteor Width`，不要先降低 `Possession Imprint Meteor Glow`，以免流星失去辨识度。
3. 如果左下角图标较小，建议使用 `Width = 32–38`、`Tail Length = 0.25–0.34`。
4. 如果场景中附身频繁，建议使用 `Speed = 1400–1800`，使连续流星保持清晰而不过度堆积。

## 5. 验收清单

- 附身成功时，流星从怪物当前位置出现并飞向正确的罪印图标。
- 流星飞行期间，目标图标数字保持原值。
- 流星抵达后，目标图标数字增加；其他罪印图标不变化。
- 暂停 / 子弹时间期间，HUD 动效仍按真实 UI 时间飞行，不会因为战斗时间缩放而卡住。
- 隐藏 HUD、缺少摄像机或图标引用失效时，罪印数量仍能正确刷新。
- 修改 `Meteor Speed` 与 `Meteor Color` 后重新进入 Play Mode，确认飞行节奏和颜色符合当前场景的可读性要求。
