## 一、系统流程概览

### 1.1 启动流程

| 模式 | 如何进入 | 表现 |
|---|---|---|
| **正式流程**（推荐团队验收用） | 场景 `GameManager` 勾选 `useFormalFlow` | 启动后先进**主菜单**，由玩家点击进入对局；调试显示（F2 面板 / 作弊提示 / 剩怪面板）全部隐藏 |
| **调试模式** | 不勾选，直接 Play 对局场景 | 直接进入对局；F2 调试面板、作弊快捷键、剩怪面板可用 |

### 1.2 主菜单

| 按钮 | 行为 |
|---|---|
| **开始游戏** | 无存档：直接新开一局；有存档：弹窗确认"会覆盖原进度"，确认后清档新开 |
| **继续游戏** | 有存档才可点（无存档自动置灰）；点击回到最近存档点继续 |
| **退出游戏** | 确认弹窗后退出程序 |

### 1.3 对局流程（波次循环）

```
地图生成（种子决定，同一局内保持一致）
  → 波次开始（数量波/时间波）
  → 怪物清场
  → 弹选卡（timeScale 暂停，选卡/重掷）
  → 选卡结束 → 下一波
  → ……（循环）……
  → 最后一波结束 → 对局结束
```

- **地图**：由种子生成，同一种子同一张图；调试可用固定种子复现。
- **ESC 暂停菜单**：可返回主菜单（进度保留）或重开本局（进度清空）。
- **选卡界面退出游戏**：重进后自动补弹本次选卡，且候选卡与退出时一致。

## 二、保存功能（当前实现）

### 2.1 保存时机（自动，无需手动）

| 时机 | 说明 |
|---|---|
| **波次清场后** | 场上怪已清空时自动存档（此时退出，重进从下一波开始） |
| **选完卡之后** | 覆盖上一份存档，记录本次选卡结果与玩家最终位置 |

> 存档在**游戏过程中自动完成**，玩家无需任何操作。

### 2.2 保存内容

| 内容 | 说明 |
|---|---|
| 波次进度 | 已完成到第几波，继续时从下一波开始 |
| 已获得卡牌 | 本局选过的卡能力 |
| 玩家状态 | 灵魂位置 / 生命 / 灵魂时间 |
| **附身状态** | 若退出时正附身某怪，重进后恢复附身在该怪上（血量/位置一致） |
| **场上尸体** | 退出时可附身的尸体，重进后原样还原，可再次附身 |
| 地图种子 | 重进后地图与退出时一致 |

### 2.3 继续方式

主菜单点 **"继续游戏"** → 回到最近存档点：
- 波间存档 → 从下一波开始
- 选卡中退出 → **补弹本次选卡**（候选卡与退出时一致，由种子/存档决定，不重新随机）

> **注意**：存档后关闭游戏，再**直接 Play 进入对局场景**（调试模式，不经主菜单）**不会读取存档**——直接进的是全新对局。
> 读取存档的唯一入口是**主菜单 → 继续游戏**。正式流程（`useFormalFlow`）下启动自然先进主菜单，正常走"继续"即可。

### 2.4 已知边界（设计如此，非缺陷）

| 场景 | 行为 |
|---|---|
| 波次**进行中**退出 | 不保存当前波细节，回到最近一次波间存档点（当前波需重打） |
| 重开 / 对局结束 | 存档清除，需从新局开始 |
| 存档槽位 | 当前为单槽位（新存档覆盖旧存档） |

## 三、调试能力（团队开发用）

| 能力 | 用法 |
|---|---|
| 固定种子复现地图 | `GameManager` → `World Seed` 勾选 `useFixedSeed` 填种子值，新局即同一张图 |
| F2 调试面板 | 左侧地图流送信息 + 右侧已获得卡片能力面板（仅调试模式可见） |
| 作弊快捷键 | 数字键解锁卡 / Q/Space 附身调试（仅调试模式可用） |
