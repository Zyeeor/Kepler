# 卡牌图鉴基础功能开发案

**状态：** Draft / 基础功能方案  
**适用模块：** 局外系统（Meta / Out-of-Run）  
**设计依据：** `Canonical/Content/Meta_Progression_Systems_Baseline_v1.0.md`  
**界面参考：** 卡牌收集原型（分类页签 + 单行横向卡牌带）

---

## 1. 目标

实现局外「卡牌图鉴（Card Archive）」：记录玩家在对局中见过和取得过的卡牌，并按七宗罪与通用分类提供回顾入口。

系统仅承担收集、展示与回顾功能，**不提供战斗加成、装备、升级、分解或交易能力**。

### 1.1 本期范围

- 记录卡牌的未知、已知、已解锁三种状态；
- 按七宗罪与通用分类浏览卡牌；
- 展示全局与分类收集进度；
- 查看已知、已解锁卡牌详情；
- 支持新卡提示与进入可视区域后的清除；
- 为已解锁卡展示 Mythic / System 双线包装文本与稳定的中性机制摘要；
- 兼容删除、禁用与改版后的历史卡牌记录。

### 1.2 不在本期范围

- 卡牌装备、升级、养成、分解、交易；
- UGC 卡牌创作、下载、分享或编辑器；
- 账号体系、排行榜、社交展示；
- 以图鉴为入口提供任何局内数值强化。

## 2. 界面结构

### 2.1 主界面

| 区域 | 功能 |
|---|---|
| 标题区 | 显示「卡牌图鉴」，提供返回或关闭操作。 |
| 分类页签 | 切换 `傲慢、色欲、怠惰、暴怒、嫉妒、贪婪、暴食、通用` 八类卡牌。 |
| 收集进度 | 显示当前分类与全局的“已解锁 / 当前有效总数”。 |
| 横向卡牌带 | 当前分类的全部卡位按固定顺序单行横向排列；超出可视范围时通过横向拖动浏览。 |
| 新内容提示 | 分类存在未读新卡时显示提示；卡牌实际进入可视区域后才清除。 |
| 横向滚动条 | 反映当前分类的横向浏览位置，可作为拖动位置反馈。 |

### 2.2 横向拖动交互

- 玩家可按住卡牌带空白区或卡位并向左、向右拖动，平移浏览当前分类的全部卡牌；
- 拖动距离超过点击阈值时，取消本次卡牌点击，避免浏览过程中误打开详情；
- 拖动停止后保持当前位置，不强制吸附；
- 到达首张或末张时限制继续越界，可保留轻微回弹作为边界反馈；
- 鼠标滚轮在卡牌带区域内默认映射为横向滚动；触控设备使用单指水平滑动；
- 已知与已解锁卡位可点击打开详情页；未知卡置黑并禁用点击；
- 切换分类后，横向位置重置至首张卡位。

### 2.3 卡牌详情覆盖层

- **已解锁：** 展示卡面、卡名、所属分类、卡牌 ID、中性机制摘要、当前 Display Profile 下的 Mythic / System 包装文本，以及首次取得时间与累计取得次数；
- **已知：** 可打开基础详情，展示卡面、卡名、所属分类与卡牌 ID；效果说明、中性机制摘要、Mythic / System 包装文本和收录数据全部以锁定态隐藏；
- **未知：** 卡位以纯黑遮罩置黑，按钮禁用、无点击反馈，不打开详情页。

## 3. 收集状态

卡牌只使用以下固定术语：

| 状态 | 触发条件 | 可见内容与交互 |
|---|---|---|
| 未知 | 从未出现在 Card Offer 中 | 卡位以纯黑遮罩置黑；隐藏名称、卡面与效果；不可点击。 |
| 已知 | 出现在 Card Offer 中但未被选择 | 可点击查看卡面、名称、所属分类与卡牌 ID；效果说明与全部收录信息锁定隐藏。 |
| 已解锁 | 玩家确认选择过该卡 | 可点击查看完整信息、取得标记、首次取得时间与取得次数。 |

状态流转：

```text
未知
  └─ Card Offer 显示 → 已知
       └─ 玩家确认选择 → 已解锁
```

规则：

- 已解锁状态不可回退；
- 失败 Run 中见过或选择的卡牌同样保留记录；
- 已知卡仅开放基础身份信息，效果相关文本与数据维持锁定态；
- 未知卡必须置黑、禁用点击，并隐藏全部卡牌信息。

## 4. 数据设计

### 4.1 卡牌静态内容

图鉴不复制卡牌配置，按 `cardId` 查询现有卡牌内容数据。

建议读取字段：

```text
cardId
sin / category
isDisabled
displayOrder
neutralMechanicSummary
mythicName / mythicDescription
systemName / systemDescription
cardArtwork
```

### 4.2 玩家图鉴存档

图鉴数据属于长期 Profile 存档，必须与单局 Run 数据分离。

每张卡至少持久化：

```text
cardId
seen
unlocked
firstSeenAt
firstUnlockedAt
selectedCount
isNewUnread
contentVersion
```

字段语义：

- `seen`：是否在 Card Offer 中出现过；
- `unlocked`：是否被玩家正式选择过；
- `firstSeenAt`：首次显示时间；
- `firstUnlockedAt`：首次取得时间；
- `selectedCount`：跨 Run 取得次数，不是效果触发次数；
- `isNewUnread`：是否仍有未查看的新内容提示；
- `contentVersion`：用于兼容卡牌改版、删除与资源失效。

## 5. 核心流程

### 5.1 进入图鉴

```text
主菜单
  → 进入卡牌图鉴
  → 读取本地 Profile 图鉴数据
  → 读取当前有效卡牌注册表
  → 计算全局及分类收集进度
  → 默认恢复上次浏览的分类；首次进入默认打开傲慢
```

### 5.2 切换分类

```text
点击分类页签
  → 刷新当前分类的单行横向卡牌带
  → 横向位置回到首张卡位
  → 显示当前分类“已解锁 / 有效总数”
  → 对实际进入可视区域的新卡清除 isNewUnread
  → 分类内无未读卡时，移除对应页签提示
```

### 5.3 查看详情

```text
点击已知卡位
  → 打开基础详情覆盖层
  → 显示卡面、卡名、分类与卡牌 ID
  → 隐藏效果说明、机制摘要、双线文本与收录数据

点击已解锁卡位
  → 打开完整详情覆盖层
  → 显示中性机制摘要与当前 Display Profile 的 Mythic / System 文本
  → 显示首次取得时间与累计取得次数

点击未知卡位
  → 无响应

关闭详情
  → 恢复原分类与横向滚动位置
```

### 5.4 对局事件接入

```text
Card Offer 显示卡牌
  → seen = true
  → 首次见到时写入 firstSeenAt
  → isNewUnread = true

玩家确认选择卡牌
  → unlocked = true
  → 首次选择时写入 firstUnlockedAt
  → selectedCount += 1
  → isNewUnread = true
```

## 6. 进度、分类与内容兼容

### 6.1 分类

顶层分类固定为：

- 七宗罪 Monster：各自独立页面；
- 通用：承载 Basic Universal 与 Global Slot 卡牌。

### 6.2 收集进度

- 进度分母为当前有效 Card 总数；
- 被禁用的卡牌不计入分母；
- 删除卡默认不在常规图鉴中显示，但需保留玩家历史记录；
- 卡牌池更新后自动重新计算分母，不得清空既有收集数据；
- 必要时在历史卡位或详情页标记“历史版本 / 部分内容已失效”。

### 6.3 新卡提示

- 新发现或新取得卡牌时，对应分类入口显示提示；
- 仅当玩家进入该分类且该卡实际进入可视区域后，才清除该卡的新内容标记；
- 仅进入图鉴首页不得清空全部分类提示。

---

## 7. 文本与视觉约束

### 7.1 双线文本与效果信息

- 仅已解锁卡展示中性机制摘要及 Mythic / System 包装文本；
- 已知卡的效果说明、中性机制摘要、Mythic / System 文本均显示为锁定态，不可读取；
- 已解锁卡在 First Clear 前默认显示 Mythic，First Clear 后默认显示 System，并允许手动切换；
- Mythic 与 System 必须描述同一项 Gameplay 事实，不得改变效果含义；
- 文案通过稳定的 `Text Key` / `Concept Key` 读取，禁止烧录进贴图或写死在 Gameplay 逻辑中。

### 7.2 卡位状态表现

| 状态 | 建议表现 |
|---|---|
| 未知 | 纯黑遮罩置黑，不显示剪影、名称或效果；按钮禁用且无点击反馈。 |
| 已知 | 正常卡面与名称；可点击进入基础详情，效果相关区域以锁定态遮蔽。 |
| 已解锁 | 亮金描边、取得角标或收录标记；可查看完整详情与收录信息。 |

### 7.3 横向陈列、分类与品质边界

- 当前分类的全部卡牌固定为单行横向排列，不换行、不使用纵向列表；
- 卡位按配置的 `displayOrder` 从左到右排列；未知、已知与已解锁卡牌均保留位置，避免收集状态变化导致顺序跳动；
- 卡牌带使用运行时横向位移实现浏览，卡面素材保持正交平面可复用；
- 罪色仅表示卡牌所属分类，不表示强度或稀有度；
- 不使用普通、稀有、史诗、传说等品质分级。

---

## 8. 状态与异常处理

| 状态 | 处理方式 |
|---|---|
| Loading | 读取 Profile 或卡牌注册表时显示加载状态。 |
| Empty | 当前分类没有有效卡牌时显示空状态。 |
| 全未知 | 正常显示纯黑禁用卡位，不视为异常。 |
| 历史内容缺失 | 保留历史卡位，显示“历史版本 / 部分内容已失效”。 |
| 存档缺失或损坏 | 使用安全默认数据初始化图鉴，不阻塞主菜单。 |
| 内容改版 | 重新计算有效分母，同时保留玩家已有收集历史。 |

## 9. MVP 开发拆分

### 阶段 A：数据与事件

1. 建立长期 Profile 图鉴数据结构；
2. 接入 Card Offer 的“已知”记录；
3. 接入确认选卡的“已解锁”记录；
4. 完成存档读写、版本兼容与基础调试入口。

### 阶段 B：主界面

1. 实现八个分类页签；
2. 实现分类与全局收集进度；
3. 实现单行横向卡牌带、横向滚动条与首末边界反馈；
4. 实现鼠标拖动、触控滑动及滚轮横向滚动，并区分拖动与点击；
5. 实现未知、已知、已解锁三种卡位；
6. 实现新内容提示与可视区域清除逻辑。

### 阶段 C：详情页

1. 实现卡牌详情覆盖层；
2. 接入中性机制摘要；
3. 接入 Mythic / System 文本切换；
4. 显示首次取得时间与累计取得次数。

### 阶段 D：验证与调试

1. 验证失败 Run 后发现与解锁记录保留；
2. 验证禁用、删除、改版卡牌的兼容展示；
3. 验证空分类、全未知、全解锁等边界状态；
4. 提供强制解锁、重置图鉴、模拟新卡和模拟 Display Profile 的调试能力。

## 10. 验收标准

- 主菜单可进入卡牌图鉴；
- 七宗罪与通用分类可独立切换；
- Card Offer 出现后，卡牌正确变为“已知”；
- 玩家选择后，卡牌正确变为“已解锁”；
- 未知卡以纯黑遮罩置黑，无法被点击或打开详情；
- 已知卡可打开基础详情，但仅可查看卡面、名称、分类与卡牌 ID；
- 已知卡的效果说明、中性机制摘要、双线文本与收录数据均保持锁定隐藏；
- 已解锁卡可查看完整信息、首次取得时间与取得次数；
- 进度分母只统计当前有效卡牌，禁用卡不计入；
- 新卡提示仅在卡牌进入实际可视区后清除；
- 当前分类的全部卡牌以单行横向顺序展示，且不换行；
- 鼠标拖动、触控滑动与滚轮可稳定横向浏览卡牌带；拖动时不会误触发详情打开；
- 切换分类后横向位置回到首张卡位；
- First Clear 前后默认双线显示逻辑正确，中性机制摘要始终存在；
- 删除、改版或缺失卡牌不会导致图鉴页面无法打开；
- 图鉴不提供任何战斗加成。

---

## 11. 表现层结论

本案采用“分类页签 + 单行横向卡牌带”作为当前实现方案：当前分类的全部卡牌从左至右横向排开，通过拖动滚动浏览。

已确认的可见性规则：已解锁卡可查看完整详情；已知卡可查看基础身份信息但隐藏效果；未知卡以纯黑遮罩置黑且不可点击。该规则为本次用户确认的设计覆盖，未修改 Canonical 源文件。

收集状态、存档字段、分类、进度、详情、新卡提示、双线文本与兼容策略保持为固定功能合同；后续若调整视觉表现，必须复用这些数据与业务流程，不改变收集记录语义。
