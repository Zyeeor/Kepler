## 3. 技能明细

### 3.1 Space / Movement — 飞行加速

- **状态**：`已开发但没资源`
- **Canonical 原文**：飞起并获得 **+200%** 移动速度，**持续 1 秒**；可在维持激光时调角度 / 距离；**不**建立真实空中层；**不**基础无敌 / 清弹。Playable Baseline：`Reload 0 / hp cost 20 / damage 0`。
- **行为规格**：
  - 点按触发；持续期间可转向与调激光角度 / 距离；**单次 1 秒后强制落地**；无空中续飞轴；下次起飞由 CD / Reload 门控。
  - 持 `EN-M01`：以飞行有效位移线段与合法 Enemy 碰撞体相交写入 Mark；同次 Movement 同目标最多 1 层；路径写入**不造成伤害**、不递归。
- **数值**：耗血 20；移速加成 +200%；持续 1 秒（Canonical）；CD 0（TUNABLE）。
- **Enemy 行为基线**：见本节末总基线；飞行用于调整激光角度 / 距离。
- **Ability 脚本**：`EnemyAbility_EnvyFlight`（建议）
- **Telegraph / 表现诉求**（`03`）：短方向提示；不得误读为突进伤害线或基础无敌。
- **资源表**：见 §3.4

### 3.2 LMB / Attack — 激光 + Mark

- **状态**：`已开发但没资源`
- **Canonical 原文**：
  - **玩家**：鼠标直接瞄准；**Enemy**：锁当前玩家，**禁止**「最高 HP 目标」。
  - 激光命中目标时向该目标写入 **Mark**；每个 Mark 储存目标受到伤害的 **20%**。
  - 激光可被 Greed 正面 Guard 截断；被截断伤害**不**写 Mark。
  - Playable Baseline：`Reload 0 / hp cost 10 per second / damage 2 per second`。
- **行为规格**：
  - **目标 Mark**（非 Body Record）：Mark 挂在**被命中目标**上；换身 / Q 消费 / 宽限超时清除；UI / VFX 不得表现为施放者自身能量条。
  - 允许朝瞄准方向**空射**维持光束；无合法命中则不写 Mark、不爬升 `EN-A05`。
  - Mark 存续期间计入该目标受到的**有效生命伤害**（含本激光）的 20% 写入储存；被 Guard 截断段不计。不另开「仅自身激光」或已删除 `EN-X01` 例外轴。
  - 首轮可玩：**单目标 Mark 储存上限 100**（`EN-R01` → +50% = 150）；写入比例基线 20%（`EN-R02` 再改比例）；均标 `TUNABLE`。
  - 持 `EN-A05`：同次连续合法连接中 DPS 逐步提高至最高 **50/秒**；断连 / 目标失效 / 停火归零；不改 Mark 比例或雷暴倍率。
- **数值**：耗血 10/秒；基础伤害 2/秒；`EN-A05` 封顶 50/秒。
- **Ability 脚本**：`EnemyAbility_EnvyLaser`（建议）
- **Telegraph / 表现诉求**（`03`）：Enemy 起手锁定当前玩家方向前兆；Beam 连接发射点与目标 / 瞄准点；Guard 截断在截断点终止；目标 Mark 与储存量可读。
- **资源表**：见 §3.4

### 3.3 Q / Special — 雷暴兑现

- **状态**：`已开发但没资源`
- **Canonical 原文**：将锁链雷电传导至**所有**带 Mark 的合法 Enemy；每目标结算基础雷暴 + 自身 Mark 储存伤害并**消费**自身 Mark；无合法带 Mark 目标时不启动、不收费、不进 Reload；Enemy 使用前必须预警；雷暴**不**回写 Mark。Playable Baseline：`Reload 1 / hp cost 50 / damage 10 + stored Mark damage per target`。
- **行为规格**：
  - 启动条件：场上至少 1 个合法带 Mark 目标。
  - 表现：从施放者到各 Mark 目标的短时链路；各目标独立结算与消费反馈（对照 `03`）。
  - `EN-S01`：同原位置延迟追加雷霆；每次追加独立预警 1 秒；不可递归。
- **数值**：CD 1；耗血 50；基础雷暴 **10** + 该目标 Mark 储存（TUNABLE / Playable）。
- **Ability 脚本**：`EnemyAbility_EnvyThunderstorm`（建议）
- **Telegraph / 表现诉求**（`03`）：Enemy 施放前必须显示落点 / 链路与时机；追加雷霆复用并独立预警。
- **资源表**：见 §3.4
