## 3. 技能明细

### 3.1 Space — 铺黑油

- **状态**：`待开发`
- **Canonical 规格**：
  - 沿路径留短寿命黑油
  - **Greed** 在普通油上获得移动增益
  - 明确火源可点燃；**Burning Oil 不再提供**普通油加速
- **资源表**：

### 3.2 LMB — 念力魔手

- **状态**：`待开发`
- **Canonical 规格**：
  - Body **自动积累**到库存上限（非「自动上场追敌」）
  - LMB **一次释放当前库存**（inventory dump Attack）
  - Possession 初始化获得少量魔手
  - **0 库存**：Attack 不启动、不收费
  - 已发射魔手跨 Body 继续
- **数值（TUNABLE / 工程初值候选）**：历史上限 6；Card `GR-A01` 提高上限（勿把「6→10」写死为唯一规则）
- **工程备注（Presentation / pathing，非 Content）**：魔手可先沿侧面绕行再扑向目标；路径预览可见，无目标则消失——阶段 B 可作表现参考，**不得**升格为 Canonical 新机制（已删除 `GR-A04` 不得借此补回）
- **资源表**：

| 资源用途 | 资源名称 | 状态 | 备注 |
|---|---|---|---|
| 魔手 | （待填） | 策划未明确 | |

### 3.3 Q — 大手 Guard / 吸收转化

- **状态**：`待开发`
- **Canonical 规格**：
  - 方向明确的**正面** Guard
  - Guard 期间**不能**同时倾泻魔手
  - 吸收正面合法飞行攻击；截断正面激光 → 转化为魔手库存
  - **空开也视为正常释放**：收费 / 进 Reload
  - **不**基础防：AoE、Field、Pull、Burning、侧后方
- **禁止**用旧「吸收任意伤害 1s，伤害量/100→手数」作为基线公式（转化档位走 Canonical + `GR-S01` 等 Card）

### Enemy 行为基线（Canonical）

> 铺油建立路径 → 累积并释放魔手 → 对明确正面威胁使用 Guard → 将吸收结果转化后反压。
