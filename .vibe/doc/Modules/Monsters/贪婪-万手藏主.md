## 3. 技能明细

### 3.1 Space — 铺黑油

- 沿路径留下短寿命普通黑油；踏入其中的合法Enemy减速。
- 明确火源可点燃；Burning Oil不再提供普通黑油减速。
- `GR-M01`扩大黑油路径长度与覆盖范围。

### 3.2 LMB — 念力魔手

- Body自动积累到库存上限；LMB一次释放当前库存；0库存不启动、不收费。
- Possession初始化获得少量魔手；已发射魔手跨Body继续。
- `GR-A01`提高库存 / 单次释放上限；`GR-A02` / `GR-A03`只在魔手造成致命后派生。

### 3.3 Q — 大手Guard / 吸收转化

- 方向明确的正面Guard；期间不能同时倾泻魔手。
- 吸收正面合法飞行攻击、截断正面激光并转化库存。
- 空开也收费 / 进入Reload；不防AoE、Field、Pull、Burning、侧后方。

### Enemy行为基线

> 铺油建立减速路径 → 累积并释放魔手 → 对明确正面威胁使用Guard → 将吸收结果转化后反压。
