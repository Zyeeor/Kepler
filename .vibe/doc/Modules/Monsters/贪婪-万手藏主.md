## 3. 技能明细

### 3.1 Space / Movement — 铺黑油

- **状态**：`已开发但没资源`
- **Canonical 原文**：向前方释放短寿命黑油；站在自身**普通黑油**上的**玩家 / Possessed Greed 获得加速**；明确火源可点燃；`GR-M01` 扩大路径长度与覆盖，并使 Enemy 踏入时减速。Playable Baseline：`Reload 0 / hp cost 10 / damage 0`。
- **行为规格**：
  - **基线**：普通黑油仅给玩家 / Possessed Greed **加速**；基线**不**使 Enemy 减速。
  - 首轮可玩：加速 **+50%** 移速；油带寿命 **4s**；宽度约 **1.5m**（均 `TUNABLE`）。
  - 明确火源可点燃 → **Burning Oil**：不再提供普通黑油加速，也不继承 `GR-M01` 减速；与愤怒砸地点燃共用 `BurningOil` 状态标签。
  - `GR-M01`：扩大路径长度与覆盖；踏入的合法 Enemy **减速**（多片只取最高；燃烧油不继承）。
  - `GR-M02`（圣路恩赐）：位于**自身普通黑油**内时免疫**地形来源伤害**；离开立即失效；不防直接攻击 / 接触伤害；**不**沿用旧减速叠层语义。
- **数值**：耗血 10；伤害 0；加速 / 寿命 / 宽度见上。
- **Enemy 行为基线**：见本节末；铺油建立玩家机动路径。
- **Ability 脚本**：`EnemyAbility_GreedBlackOil`（建议）
- **Telegraph / 表现诉求**（`03`）：普通油传达己方加速区；持 `GR-M01` 时叠加 Enemy 减速可读性；燃烧态可辨。
- **资源表**：见 §3.4

### 3.2 LMB / Attack — 念力魔手

- **状态**：`已开发但没资源`
- **Canonical 原文**：每秒生成 1 只魔手环绕本体，基础库存上限 **6**；LMB 以 **0.2 秒**间隔依次释放所有库存；一次释放总计消耗 **20 HP**；无合法目标的魔手消失；追踪距离内最近敌人；Possession 初始化获得少量魔手；0 库存不启动、不收费；已发射魔手跨 Body 继续；`GR-A01` 提高库存 / 单次释放上限；`GR-A02` / `GR-A03` 仅在魔手造成致命后派生。
- **行为规格**：
  - 库存：上限 6（`GR-A01` 再扩）；每秒 +1；附身初始 **2**（TUNABLE「少量」）。
  - 0 库存：不启动、不收费、不进 Reload。
  - `GR-A07`（迂回纳贡）：每只已释放魔手先沿固定左/右侧翼弧线离开正前方，再收束追向合法目标；按释放序号**奇偶交替左/右**；同帧多手保持交替；无目标消失；不改伤害 / 数量 / 寿命 / 派生次数。
  - `GR-A02`：致命后一次最近目标再索敌；`GR-A03`：致命后生成 1–2 新手且不可递归。
- **数值**：一次倾泻耗血 20；释放间隔 0.2s；库存上限 6 / 生成 1/秒（Canonical）。
- **Ability 脚本**：`EnemyAbility_GreedHands`（建议）
- **Telegraph / 表现诉求**（`03`）：库存 UI；持 `GR-A07` 侧翼弧线可读，不得读成已删除分裂。
- **资源表**：见 §3.4

### 3.3 Q / Special — 大手 Guard / 吸收转化

- **状态**：`已开发但没资源`
- **Canonical 原文**：大手保护身体，吸收**所有伤害**；基础持续 **1 秒**；期间**不能移动**，也不能倾泻魔手；每 **100** 点实际吸收伤害转化 1 只魔手；空开也收费 / 进入 Reload；`GR-S01` 每 **60** 点转 1 手；`GR-S04` 持续 **3** 秒，可再次 Special 提前结束并立即 Reload。
- **行为规格**：
  - **判定**：全身吸收所有对 Body 的有效生命伤害与可吸收直接攻击；**禁止**旧稿「仅正面 Projectile / 激光」。Pull 位移本身不转手。
  - Guard 期间地形伤害：按吸收合同处理（有 `GR-M02` 时普通油上地形伤害本就不进）；无 `GR-M02` 时地形伤仍可被 Guard 吸收并计入转化。
  - **表现**：可视可保留身前大手，但判定按全身吸收；HUD / 教学文案写「护体吸收」，避免「侧后方不受伤」误读。
  - 空开：仍完成释放、收费、进 Reload；零吸收不播转化成功反馈。
- **数值**：基础时长 1s（`GR-S04`→3s）；转化 100→1 手（`GR-S01`→60→1）。
- **Ability 脚本**：`EnemyAbility_GreedGuard`（建议）
- **Telegraph / 表现诉求**（`03`）：Enemy 启动前与有效期内可读；强调定身 / 吸收中；转化回流库存 UI。
- **资源表**：见 §3.4
