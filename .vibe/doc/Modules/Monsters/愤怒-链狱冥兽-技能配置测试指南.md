# 愤怒-链狱冥兽 — 技能配置测试指南

> 阶段 B 对齐记录：2026-08-19  
> Prefab：`Assets/Prefabs/Monster/wrath_new.prefab`  
> Cheat：`MonsterCheatCatalog` → `愤怒`  
> 模型：复用 `Wrath(full)` 网格 / 视觉层级（工程名候选 `MDL_MON_WRATH_BASE`）  
> 合同要点：基础龙卷风 **2.0s**，结算间隔 **0.5s**；当前 6 张 `WR-*`。

## 1. 入口

1. 打开 `CombatTest`（或当前战斗测试场景）。
2. 确认 `MonsterPossessionCheat` 引用 `MonsterCheatCatalog`，并关闭会拦截热键的开局双选卡。
3. 刷出并附身 `愤怒`（`wrath_new`）。
4. 另刷木桩 / 普通 Enemy 至少 1 个；需要黑油点燃时再刷贪婪黑油或等价占位。
5. 调试开卡解锁指定 `WR-*` 后重新刷出或重新附身，使 CardManager 把解锁写到 Ability `upgrades`。

基础数值（TUNABLE 首轮）：移速 4 / 血量 150；Space `CD=3 / 耗血=15`；LMB `CD=2 / 耗血=10 / 砸地伤=25`；Q `CD=8 / 耗血=40 / tick伤=12`。

## 2. 三槽基线

| 输入 | 操作 | 期望 |
|---|---|---|
| Space | 瞄准前方有合法地面 | 钩向落点；钩头不造成基础伤害；成功抵达后站稳。 |
| Space | 前方无合法落点 | **不启动、不收费、不进 CD**；不应播完整抓地 Impact。 |
| LMB | 任意（可无目标） | 一次砸地范围伤 + 生成 Burning 区（5/s × 3s）。 |
| LMB | 同一区域再次砸地 | Burning **刷新时长至 3s**，DPS 不叠乘。 |
| LMB | 砸在普通黑油上 | 触发点燃通道（`Ignite` / `IgniteOil` 消息）；贪婪正式油接入后应切燃烧油表现。 |
| Q | 无目标也可放 | 建立空龙卷风并收费进 Reload；持续 **2.0s**，**每 0.5s** 结算。 |
| Q | 范围内有敌人 / 灵魂 | 向心 Pull（轻/中/重不同步进）；**不 Stun**；被拉玩家仍可移动与 Space。 |
| 换身 / Body Fatal | Q 进行中 | 立即结束旋转 / Aura / 风暴移速 Effect。 |

## 3. 卡牌对照（6 张）

| effectId | 解锁后检查 |
|---|---|
| `WR-M01` | 钩索行进路径产生**一次**路径伤害；不留持续火迹。 |
| `WR-M02` | 合法搜索距离 ×1.5；抵达合法落点后短冲击；未抵达不生成冲击。 |
| `WR-B01` | 按缺失耐久比例提高砸地伤害与范围，并缩短 Attack CD；三项各自最高 +50%；不改播放速度。可用 `EnemyAbility_WrathSlam.GetMartyrReadouts` 读三值。 |
| `WR-B02` | 取得后常驻贴身燃烧光环；不依赖低耐久；换身 / 致命结束。 |
| `WR-S01` | 仅龙卷风有效期内 Body 移速 ×4（+300%）；不延长、不加强 Pull、不 Stun。 |
| `WR-S03` | 龙卷风时长变为 **4.0s**；仍每 0.5s 结算；无终段冲击。 |

退役且不补回：`WR-A01`、`WR-M03`、`WR-S02`、`WR-TG01`。旧工程 `Wrath01` / `Wrath02` 仅服务 `Wrath(full)`，不要当作 `wrath_new` 需求。

## 5. 已知限制

- Play Mode 全量手感验收需人工在 `CombatTest` 跑完本指南；本轮 Stage B 以组件装配与合同参数落地为准。
- 贪婪黑油点燃依赖对方实现 `Ignite*` 消息接口；未接入时仅保证调用点存在。
- 重量→Pull 使用 `MonsterActor.BodyType`：`Slim` 轻 / `Medium` 中 / 其余重。
- 正式美术资源行多为占位 → 相关技能 / 资源行状态为 `已开发但没资源`；无资源依赖的纯逻辑卡可为 `已完成`。
