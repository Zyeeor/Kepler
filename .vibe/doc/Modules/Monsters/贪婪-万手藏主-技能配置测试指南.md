# 贪婪-万手藏主 — 技能配置测试指南

> 阶段 B 对齐记录：2026-08-19  
> Prefab：`Assets/Prefabs/Monster/greed_new.prefab`（模型复用 `Greed（full`）  
> Cheat：`MonsterCheatCatalog` →「贪婪」（数字键按 Catalog 序）  
> 正式资源多为占位；下列以逻辑验收为主。

## 1. 入口

1. 打开 `CombatTest`。
2. 确认 `MonsterPossessionCheat` 引用 `MonsterCheatCatalog`，关闭开局双选卡（若挡热键）。
3. 数字键刷出并附身「贪婪」；另刷若干普通 Enemy 作魔手目标。
4. 开卡：附身中按住 LMB / Space / Q + 数字，解锁对应槽位的 `GR-*`。

基线数值（TUNABLE）：移速 8 / 血量 200；Space 耗血 10；LMB 一次倾泻耗血 20；Q Guard 耗血 15、CD 4s。可开 `suppressPossessionDrain` 专注验证机制。

## 2. 三槽基线

| 输入 | 操作 | 期望 |
|---|---|---|
| Space | 向前铺油 | 短寿命普通黑油带；玩家 / Possessed Greed 站上加速（约 +50%）；**Enemy 不减速**。 |
| LMB | 0 库存 | 不启动、不收费、不进 Reload。 |
| LMB | 有库存 | 一次倾泻当前库存；间隔 0.2s；总计耗血 20；无合法目标的手消失。 |
| 附身瞬间 | — | 初始魔手 **2**（不随 `GR-A01` 上限等量填满）；之后每秒 +1，上限 6。 |
| Q | 开启 Guard | 持续 1s；定身（不能移动）；期间 LMB 倾泻被拒绝；吸收所有对 Body 有效伤害并按 100→1 转手。 |
| Q | 空开 | 仍收费 / 进 Reload；零吸收不播转化成功反馈。 |
| 已发射魔手 | 换身 | 场上已发射魔手继续追踪，不随 Body 销毁。 |

## 3. 卡牌对照

| effectId | 槽 | 解锁后检查 |
|---|---|---|
| `GR-M01` | Space | 油更长更宽；合法 Enemy 踏入普通油减速；燃烧油不继承减速；多片取最高意图。 |
| `GR-M02` | Space | 站在自身普通油上忽略地形伤害；离开立即失效；不防直接攻击。 |
| `GR-A01` | LMB | 库存 / 单次释放上限提高（工程初值 10）；附身初始仍为少量 2。 |
| `GR-A02` | LMB | 魔手致命后若有最近合法 Enemy，再索敌一次；无目标消失。 |
| `GR-A03` | LMB | 致命后派生 1–2 新手；派生不可再触发本卡。 |
| `GR-A07` | LMB | 已释放手先侧翼弧线再收束；奇偶交替左/右；不改伤害/数量。 |
| `GR-S01` | Q | 每 60 点实际吸收转 1 手。 |
| `GR-S04` | Q | Guard 持续 3s；期间再次 Q 提前结束并立即 Reload。 |

已删除且不得补回：`GR-A04`/`A05`/`A06`、`GR-M03`/`M04`、`GR-S02`/`S03`、`GR-TG01`（CardLibrary `disabledEffectIds`）。
