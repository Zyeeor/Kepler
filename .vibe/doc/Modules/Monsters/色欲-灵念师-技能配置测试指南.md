# 色欲-灵念师 — 技能配置测试指南

> 阶段 B：2026-08-19  
> Prefab：`Assets/Prefabs/Monster/lust_new.prefab`  
> Anchor：`Assets/Prefabs/Monster/PF_MON_LUST_ANCHOR.prefab`  
> Cheat：`MonsterCheatCatalog` → `色欲`  
> 当前输入：`Q = Special`，`E = Bullet Time`（Owner 例外，本轮不改）。

## 1. 入口

1. 打开 `CombatTest`（或当前战斗测试场景）。
2. 确认 `MonsterPossessionCheat` 已引用 `MonsterCheatCatalog`；建议关闭开局双选卡以免挡热键。
3. 刷出并附身 **色欲**；另刷 ≥2 个普通 Enemy 作 Link / Pull 目标。
4. 测卡：调试开卡解锁指定 `LU-*` 后重新刷出或重新附身，使 CardManager 应用到该 Body。

基础数值（TUNABLE）：Space `CD=1 / 耗血=20`；LMB `CD=2 / 耗血=1 / 段伤=20`；Q `CD=6 / 耗血=30 / 伤=25`。可开 `suppressPossessionDrain` 专测机制。

## 2. 三槽基线

| 输入 | 操作 | 期望 |
|---|---|---|
| Space | 无 Anchor | 向瞄准短位移约 4m；**起点**留主 Anchor（粉球占位）；进入 CD。 |
| Space | 已有 Anchor | 与 Anchor **换位**；不额外留第二个 Anchor；换身 / 8s 寿命到期清除。 |
| LMB | 无 `LU-A04` | 雾去程 + 回程；两段可分别命中；命中写 Link（每目标 1 层，刷新不叠）。 |
| LMB | 无目标空放 | 雾仍沿瞄准飞出再回；收费一次。 |
| Q | 无 Anchor 或无 Link | **不启动**、不耗血、不进 CD。 |
| Q | Anchor + ≥1 Link | 目标拉向 **Anchor**（非自身）；窗口 0.60s；结算伤害；消费 Anchor 与相关 Link；不 Stun。 |
| 换身 | 任意 | 立即清 Anchor / Link；`LU-S06` 隔离登记清除。 |

## 3. 卡牌对照

| effectId | 解锁后检查 |
|---|---|
| `LU-M03` | 仅**换位成功**后：旧 Anchor 位延迟 0.15s、30 伤、2.5m；首次留 Anchor 不爆。 |
| `LU-M05` | 每次本体 Attack 启动后，有效 Anchor 延迟 0.10s 模仿（伤害 50%）；不二次触发模仿；无 Anchor 无效。 |
| `LU-A04` | Attack 改为 0.5→4m 环扩 0.8s；每目标每实例最多命中 1 次并写 1 Link。 |
| `LU-M05`+`LU-A04` | 本体环与 Anchor 环为**两实例**；同目标可各中一次（100%+50%）；Link 只刷新。 |
| `LU-A03` | Linked 目标死亡后约 0.10s、30 伤、2.5m；每目标一次；可连锁。 |
| `LU-S05` | 同次 Pull 窗口内目标互撞（距≤0.75m）：中点 25 伤、2m；每目标每次 Special≤1 次。 |
| `LU-S06` | Pull 窗口 + 结束后 0.15s：被拉来源对玩家当前 Possessed Body 的 Direct/新弹伤害隔离；不清理既有 DoT/地面。 |
| `LU-TG01` | Body 移速 ×1.15；三槽 CD ×0.70；不缩前摇/Telegraph。 |

退役卡（不得出现在可选池 / 不得当需求）：`LU-A01/A02`、`LU-M01/M02/M04`、`LU-S01`–`S04`。

## 5. 已知限制

- 正式美术资源（动画 / VFX / UI / 模型）均为占位 → 分项多为 `已开发但没资源`。
- AI 对灵魂态玩家无法写 Link（Link 仅 Enemy）；AI 基线需在玩家已附身其它怪时验证 Pull。
- `LU-S06` 对「牵引前已存在」的 DoT / 地面实例不清除；隔离走 `LustPullDamageGate`（Direct + 经 Ability/Projectile 的结算）。
- 重量曲线：默认 Enemy=中(60%)、附身 Body=轻(100%)；重(30%)需改 `LustBodyState.bodyWeight`。
- Play Mode 全量验收需人工按本表跑一遍。
