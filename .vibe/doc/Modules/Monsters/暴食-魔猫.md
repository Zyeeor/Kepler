## 3. 技能明细

### 3.1 Space — 小猫化

- **Canonical**：约50%体型，持续3秒，移速+100%，重量变轻；不改变受击层；再次Space、持续结束或Special恢复捕食态；普通Attack默认恢复，持有`GL-M01`后Attack不再退出。
- **工程事实**：缩放50%、3秒、移速×2已落地；正式小猫模型与进入/退出表现缺失。

### 3.2 LMB — 深渊巨口

- **Canonical**：指定地面位置，施放时快照，0.5秒后生成，不持续追踪；Enemy与玩家版本均显示清晰危险区。
- **工程事实**：预警0.7秒、运行时红圆柱占位，`telegraphPrefab` / `blastVfxPrefab`为空；需改为当前0.5秒Baseline。

### 3.3 Q — 吞噬 / 临时复制E槽

- **Canonical**：魔猫形态前方约1米扇形咬合；命中Enemy获得`Overfed`，并复制目标`E / Skill Ability`临时替代暴食E槽；复制技能成功使用一次后恢复吞噬；换身清除Overfed和未使用复制技能。基础不吞飞行攻击，`GL-S03`为例外。
- **Enemy例外**：Enemy不使用玩家专属临时复制E槽，但保留吞噬、Overfed和二次咬合核心Payload与表现语义。
- **工程事实**：当前有吞噬 / Overfed / 三张`GL-S*`旧逻辑，但缺复制E槽，首次吞噬回复仍为20而非当前50。

### Enemy行为基线

> 小猫态追击 / 重定位 → 在预测位置放巨口 → 近距离尝试吞噬 → 获得Overfed后优先二次咬合；Enemy不使用临时复制E槽。
