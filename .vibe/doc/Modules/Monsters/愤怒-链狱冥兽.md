## 3. 技能明细

### 3.1 Space — 钩索位移

- **状态**：`待开发`
- **Canonical 规格**：
  - 钩合法地面 / 位移点；将自身拉向目标位置
  - **无合法点不启动**
  - 钩头 **不是** Attack Projectile（基线无路径伤害）
- **路径伤害**：仅 Card `WR-M01` 焚途誓约，**不是**基础词条
- **资源表**：

| 资源用途 | 资源名称 | 状态 | 备注 |
|---|---|---|---|
| 扔钩→抓地→借力前冲 | （待填） | 策划未明确 | |

### 3.2 LMB — 砸地 + Burning

- **状态**：`待开发`
- **Canonical 规格**：
  - 范围伤害；留燃烧
  - 可点燃 Greed Oil
  - **满耐久时本身就必须好用**（低耐久强化是 Card，不是基线依赖）
- **数值（TUNABLE / 工程初值候选）**：伤害 5/秒×3 秒等，Playable 调参
- **资源表**：

| 资源用途 | 资源名称 | 状态 | 备注 |
|---|---|---|---|
| 双拳砸地 + 地板碎裂 | （待填） | 策划未明确 | |
| 燃烧效果 | （待填） | 策划未明确 | |

### 3.3 Q — 暴怒锁链

- **状态**：`待开发`
- **Canonical 规格**：
  - 短时旋转；持续伤害；强 Pull
  - 轻 / 中 / 重产生不同位移
  - **不 Stun**
  - 被 Enemy Pull 的玩家仍保留移动与 Space 输入
- **禁止**：把旧「龙卷吸入 2s + 过程 +300% 移速」当作唯一基线（移速类强化若存在须走 Card / Decision）

### Enemy 行为基线（Canonical）

> 钩索逼近 → 砸地建立燃烧区 → 合法距离内开启锁链 Pull → 恢复 / 再接近。
