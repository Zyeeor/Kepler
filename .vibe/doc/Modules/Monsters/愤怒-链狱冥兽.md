## 3. 技能明细

### 3.1 Space — 钩索位移

- **状态**：`待开发`
- **Canonical**：将自身钩向前方合法地面 / 位移点；无合法点不启动；钩头不是 Attack Projectile；基础只负责位移。`WR-M01` 路径伤害；`WR-M02` 提高距离并在合法落点冲击。
- **行为规格**：
  1. **点按**：沿瞄准向前搜索合法落点；**无合法点 → 不启动、不收费、不进 Reload**。
  2. **`[AI裁定]` 合法点**：可站立地面 / Walkable（项目地面层）；最大搜索距离 **8.0m（TUNABLE）**；`WR-M02` 将距离乘以 **1.5（TUNABLE）**。
  3. 钩头仅视觉 + 落点判定，**基础不伤害、不对冲、不留持续命中体**。
  4. 失败反馈：仅 UI/短音「无落点」级提示，**不**播完整抓地 Impact。
- **资源表**：见 §3.4。

### 3.2 LMB — 双拳砸地 + Burning

- **状态**：`待开发`
- **Canonical**：双拳砸地范围伤害；命中区域燃烧 **每秒 5 点、持续 3 秒**；可点燃 Greed 普通黑油；满耐久时本身就必须好用。
- **行为规格**：
  1. 落拳一次范围结算 + 生成 Burning 地面区。
  2. **`[AI裁定]` Burning 叠层**：同一目标 / 同一地面格上再次施加 → **刷新剩余时长至 3s**，DPS 保持 5/s（不无限叠 DPS）；快照在施加时写入。
  3. **`[AI裁定]` 与黑油接口**：Wrath Burning 区与明确火源同属「可点燃 Greed 普通黑油」通道；踩入普通黑油 → 切换为燃烧油表现（复用贪婪燃烧油语义，不另造第二套点燃规则）。
  4. 持 `WR-B01` 时伤害与 Attack 外显范围随缺失耐久比例上涨（各最高 +50%）。
- **数值**：砸地伤 25（TUNABLE）；Burn 5/s × 3s（Owner Baseline）。
- **资源表**：见 §3.4。

### 3.3 Q — 暴怒锁链 / 龙卷风

- **状态**：`待开发`
- **Canonical**：触角将范围内敌人吸入中心，形成基础持续 **2 秒** 龙卷风式牵引；**每 0.5 秒**结算一次伤害；轻/中/重不同牵引位移；不 Stun；被 Enemy Pull 的玩家仍保留移动与 Space。`WR-S01` 期间 Body +300% 移速；`WR-S03` 时长 +2s。
- **行为规格**：
  1. **`[AI裁定]` 无目标也可启动**（建立空龙卷风并收费进 Reload）；有合法目标则吸入中心。Owner 若改为「无目标不启动」可覆盖正文。
  2. 基础持续 **2.0s**；持 `WR-S03` → **4.0s**；tick **每 0.5s**。
  3. **`[AI裁定]` 重量→每 tick 向心位移**：以 `PullStepMax = 1.2m（TUNABLE）` 为 100%——**轻 100% / 中 55% / 重 25%**；不 Stun。
  4. 换身 / Body Fatal → 立即终止旋转与 Aura（`01`）。
  5. Enemy 版须有范围 + 时机 Telegraph（`03`）。
- **资源表**：见 §3.4。
