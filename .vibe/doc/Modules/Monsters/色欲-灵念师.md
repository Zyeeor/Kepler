## 4. 技能明细

### 4.1 Space — 魅影换位 / Anchor

- **状态**：`已开发但没资源`
- **Ability 脚本**：`EnemyAbility_LustAnchorSwap.cs`
- **Canonical 原文要点**：位移；起点留 Anchor；再次使用可与 Anchor 换位；基础只维护一个主 Anchor；新 Anchor 替换旧 Anchor；Anchor 不可攻击 / 不被 Pull；有寿命；换身清除。
- **行为规格**：
  1. **点按** Space：若当前**无**有效主 Anchor → 向瞄准 / 输入方向短位移，在**起点**生成主 Anchor，进入 Reload。
  2. 若已有有效主 Anchor → 与 Anchor **换位**（本体↔Anchor 位置交换），进入 Reload；持 `LU-M03` 时在**被交换的旧 Anchor 位置**延迟 0.15s 引爆（见 Card）。
  3. 场上始终最多 **1** 个主 Anchor；新建立即销毁旧 Anchor（含其 VFX/UI）。
  4. Anchor：**不可选中为攻击目标**、**不被任何 Pull 位移**、不视为 Enemy / Corpse / 召唤物。
  5. **`[AI裁定]` Anchor 默认寿命 8.0s（TUNABLE）**：自生成或被「替换刷新」时重置计时；到期销毁且不爆炸（`LU-M03` 仅换位成功触发）。
  6. 换身 / Body Fatal → **立即清除** Anchor（`01` Body-bound）。
  7. **不**基础无敌；撞墙按项目通用位移夹紧；无目标仍可放（自位移技能）。
- **数值（TUNABLE 首轮）**：CD 1；耗血 20；位移距离 4.0m；Anchor 寿命 8.0s。
- **Enemy 行为基线**：优先在安全距离留 Anchor，再转入 Attack 建 Link。
- **Telegraph / 表现（`03`）**：Enemy Anchor 目的地持续可读；Mythic=残影/契印，System=锚点协议标识（一事两译，同一逻辑对象）。
- **资源表**：见 §4.4。

### 4.2 LMB — 迷情往返 + Link

- **状态**：`已开发但没资源`
- **Ability 脚本**：`EnemyAbility_LustRoundTrip.cs`
- **Canonical 原文要点**：雾状攻击去程 / 回程；两段可分别命中；命中施加 Link；Link 不无限叠层；基础不对冲普通飞行攻击。
- **行为规格**：
  1. **点按** LMB：沿瞄准方向放出雾状弹道，完成**去程**后沿路径**回程**；两段**各自独立命中登记**，同一次施放只收费一次。
  2. 命中合法 Enemy → 写入 **Link（每目标最多 1 层）**；重复命中**刷新** Link 剩余时间，不叠层。
  3. **`[AI裁定]` Link 默认窗口 6.0s（TUNABLE）**：自最近一次成功写入 / 刷新起算；超时清除；目标死亡 / 换身清除施放者侧相关 Link 登记（`01`）。
  4. 基础**不对冲**普通飞行攻击；可被明确 Guard 等规则截断时按通用 Interaction。
  5. 无目标可空放（雾沿瞄准飞出再回）。
  6. 持 `LU-A04` 时整段 Attack **替换**为环形迷气（见 Card），不再去/回双段。
  7. 持 `LU-M05`：每次本体 Attack 成功启动后，当前有效 Anchor 延迟 0.10s 模仿（见 Card 与 §4.5 联动细则）。
- **数值（TUNABLE 首轮）**：CD 2；耗血 1；每段伤害 20；弹道宽度约 1.0m；Link 窗口 6.0s。
- **Enemy**：锁当前玩家方向施放往返雾。
- **资源表**：见 §4.4。

### 4.3 Q — 诱引 / 牵魂（基础 Special）

- **状态**：`已开发但没资源`
- **Ability 脚本**：`EnemyAbility_LustSoulPull.cs`
- **Canonical 前置**：有有效 Anchor；至少一个合法 Linked 目标。
- **前置失败**：不启动、不收费、不进 Reload。
- **成功行为规格**：
  1. 将**所有**当前合法 Linked 目标拉向 **Anchor 位置**（不是拉向施放者）。
  2. 每个被拉目标结算一次伤害；**不 Stun**；玩家被 Enemy Pull 时仍保留移动与 Space（对齐愤怒 Pull 可读性精神）。
  3. **重量→位移（`01` Pull×Body Weight；`[AI裁定]` 首轮曲线）**：以「满拉距」`PullMaxDistance = 6.0m（TUNABLE）` 为 100%——**轻 100% / 中 60% / 重 30%** 实际位移；重量只改位移量，**不改目的地（Anchor）**。
  4. Pull **持续窗口** `[AI裁定]` **0.60s（TUNABLE）**：窗口内持续牵引插值；窗口结束时若目标仍存活则完成伤害结算（若尚未结算）。
  5. 成功结束（含正常完成）→ **消费** Anchor 与**本次参与 Pull 的相关 Link**。
  6. **明确不是基础 Q**：击杀召唤色灵（退役 `LU-S04`）。
  7. **`LU-S05`**：同次 Pull 中 Linked 目标互撞爆炸（增强，不重解锁 Pull）。
  8. **`LU-S06`**：牵引来源伤害隔离（见 Card）。
- **数值（TUNABLE 首轮）**：CD 6；耗血 30；伤害 25；PullMaxDistance 6.0m；Pull 窗口 0.60s。
- **Enemy**：仅当 Anchor+Link 均合法时开 Pull；有前兆指向 Anchor。
- **资源表**：见 §4.4。

#### `LU-S05` 互撞合同（写入正文）

1. **检测范围**：仅「同一次」色欲 Special Pull **窗口内**、正在被牵引的合法目标两两之间。
2. **有效互撞判定 `[AI裁定]`**：两目标碰撞体发生 **Contact**，**或** 中心水平距离 ≤ **0.75m（TUNABLE）** 且均处于本批 Pull 名册。
3. **配对与同帧多对**：每个目标每次 Special **最多参与 1 次**碰撞事件；同帧多个候选对时，按**中心距升序**贪心配对（先近后远），已用目标移出池；故 4 目标最多 **2** 次爆炸。
4. **爆炸**：碰撞点（两中心中点）**25 伤、2.0m 半径**；不施 Link、爆炸本身不递归触发新的 S05；击杀其他 Linked 可走 `LU-A03`。
5. **不触发**：墙壁、Anchor、玩家 Possessed Body、未被本批牵引的单位、环境几何。

#### `LU-S06` 隔离边界合同（写入正文）

1. **有效期**：Pull 窗口内 + 结束后 **0.15s** 宽限（Card Truth）。
2. **隔离对象**：仅**被本批牵引的来源**对**玩家当前 Possessed Body** 的新伤害。
3. **隔离类别 `[AI裁定]`**（工程可用 Tag / DamageChannel）：`Direct`（近战结算）、`Contact`（贴身持续接触伤）、`Projectile`（牵引期间**新发射**的弹体）。对应建议 Tag：`State.Combat.Lust.PullDamageIsolation`（挂在玩家 Body）+ 来源侧 `State.Combat.Lust.PulledSource`。
4. **不隔离 / 不清除**：牵引**前已存在**的 DoT、地面燃烧 / 黑油等区域实例；非被牵引单位的伤害；对 Soul 的规则另循 Soul 合同（本卡只谈 Possessed Body）。
5. **不得误读**：不是全局无敌、不是减伤光环给队友、不回滚已上身的持续伤。

#### `LU-M05` × `LU-A04` 命中登记合同（写入正文）

1. 本体 Attack 与 Anchor 模仿是 **两次独立施放实例**（Anchor 延迟 0.10s，伤害 50%）。
2. **各自**维护「本实例每目标最多命中 1 次 + 最多写入 1 次 Link 尝试」。
3. 同一目标可被本体环与 Anchor 环**各命中一次**（伤害 100%+50%）；Link **不叠层**，第二次命中仅**刷新** Link 窗口。
4. Anchor 模仿**不再**触发新的模仿事件；不额外耗血。
5. 无有效 Anchor 时 `LU-M05` 不生效。

### Enemy 行为基线（Canonical）

> 留 Anchor → 往返攻击建立 Link → Anchor 与 Link 均合法时 Pull → 重新建立位置关系。
