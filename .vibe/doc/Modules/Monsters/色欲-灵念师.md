## 3. 技能明细

### 3.1 Space — 魅影换位 / Anchor

- **状态**：`待开发`
- **Canonical 规格**：
  - 位移；起点留 Anchor；再次使用可与 Anchor 换位
  - 基础只维护 **一个** 主 Anchor；新 Anchor 替换旧 Anchor
  - Anchor 不可攻击 / 不被 Pull；有寿命；**换身清除**
- **资源表**：

| 资源用途 | 资源名称 | 状态 | 备注 |
|---|---|---|---|
| 残影 / Anchor | （待填） | 已开发但没资源 | 美术追踪；正式名待填 |

### 3.2 LMB — 迷情往返 + Link

- **状态**：`待开发`
- **Canonical 规格**：
  - 雾状攻击去程 / 回程；两段可分别命中
  - 命中施加 Link；Link **不无限叠层**
  - 基础不对冲普通飞行攻击
- **资源表**：

| 资源用途 | 资源名称 | 状态 | 备注 |
|---|---|---|---|
| Link 头标 icon | （待填） | 已开发但没资源 | 美术追踪；正式名待填 |
| 迷气往返 VFX | （待填） | 策划未明确 | |

### 3.3 Q — 诱引 / 牵魂（基础 Special）

- **状态**：`待开发`
- **Canonical 前置**：
  - 有有效 Anchor
  - 至少一个合法 Linked 目标
- **前置失败**：不启动、不收费、不进 Reload
- **成功**：
  - 将 Linked 目标拉向 Anchor；造成伤害；重量影响位移；**不 Stun**
  - **消费** Anchor 与相关 Link
- **明确不是基础 Q**：击杀召唤色灵环绕（已退役 `LU-S04`，见 Appendix）
- **明确不重解锁基础 Pull**：Card `LU-S05` 只增强同次 Pull 中 Linked 互撞爆炸

### Enemy 行为基线（Canonical）

> 留 Anchor → 往返攻击建立 Link → Anchor 与 Link 均合法时 Pull → 重新建立位置关系。
