# 嫉妒-激光异形 — 技能配置测试指南

> 对应细分需求：`嫉妒-激光异形.md`  
> Prefab：`Assets/Prefabs/Monster/envy_new.prefab`  
> Cheat 显示名：`嫉妒`

## 1. 热键 / 入口

1. 打开 `CombatTest`，确认 `MonsterPossessionCheat` 可用。
2. 建议关闭 `testDoublePickOnStart`，避免挡热键。
3. Cheat 生成 / 附身「嫉妒」。
4. 另生成木桩或其它怪作为 Mark / 雷暴目标。

## 2. 基础三槽

### Space — 飞行加速

| 场景 | 期望 |
|---|---|
| 点按 Space | 耗血 20；约 1 秒移速 ×3；到期强制落地 |
| 飞行中按住 LMB | 仍可转向与调激光角度 |
| 无 `EN-M01` | 路径不写 Mark |

### LMB — 激光 + Mark

| 场景 | 期望 |
|---|---|
| 无目标空射 | 光束可维持；不写 Mark；不爬升 `EN-A05` |
| 单目标命中 | 每秒约 2 伤；目标获得 Mark；储存约 20% 有效伤害 |
| 多目标 | 默认单束；仅命中首个合法目标（无穿透时） |
| Enemy AI | 锁当前玩家，不锁最高 HP |
| Greed Guard（若已实装） | 在 Guard 点截断；截断段不写 Mark |
| 松手 / 断连 | 无 `EN-R04` 时 Mark 清除；有则进入宽限 |

### Q — 雷暴兑现

| 场景 | 期望 |
|---|---|
| 场上无 Mark | 不启动、不收费、不进 CD |
| 有 Mark 目标 | 每目标基础 10 + 储存伤害；Mark 被消费 |
| 链路 VFX | 施放者 → 各目标短时螺栓（旧 Chain VFX 占位） |

## 3. 词条对照

| CardId | 解锁前 | 解锁后 |
|---|---|---|
| `EN-A01` | 单束 | 每 3 秒短暂四目标阶段 |
| `EN-A03` | 不穿透 | 周期穿透窗口，可打后方 |
| `EN-A04` | 连接窗口约 8s | 连接更久（参数 `ConnectDuration`） |
| `EN-A05` | 固定 2/秒 | 连续合法连接爬升至最高 50/秒；断连归零 |
| `EN-M01` | 飞行无 Mark | 路径接触目标写 1 层 Mark（同次同目标最多 1） |
| `EN-R01` | 储存上限 100 | 上限 ×1.5 |
| `EN-R02` | 写入 20% | 写入比例升高（参数 `MarkWriteRatio`） |
| `EN-R04` | 断连即清 | 断连宽限内可续写 / 可 Q 兑现 |
| `EN-S01` | 单次雷暴 | 同点延迟追加两次（共 3 次落雷语义） |
| `EN-TG01` | 基础射程 | 激光 / 雷暴作用距离同步增加 |

## 4. 资源占位

当前正式美术多未挂上，Play Mode 看到的是：

- 激光 Beam / Hit：旧 `JiDu-PuGong` 参考资源

- Mark 目标⚡：程序化材质已实现；检查目标头顶位置、大小与偏移，和 Lust Link 同时存在时应以共享中心偏移左右分列。飞行拖尾 / Telegraph 仍多为空占位。

验收时注明「占位」与「正式」即可。
