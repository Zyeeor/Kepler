# 暴食-魔猫 — 技能配置测试指南

> 阶段 B 对齐记录：2026-08-19  
> Prefab：`Assets/Prefabs/Monster/gluttony_new.prefab`  
> Cheat：`MonsterCheatCatalog` → `Gluttony_new`  
> 当前输入 Owner 例外：`Q = Special`，`E = Bullet Time`。

## 1. 入口

1. 打开 `CombatTest` 或当前战斗测试场景。
2. 确认 `MonsterPossessionCheat` 已引用 `MonsterCheatCatalog`，并关闭可能拦截热键的开局选卡。
3. 刷出并附身 `Gluttony_new`；另刷至少一个带 Skill Ability 的普通 Enemy 作为吞噬目标。
4. 为测试卡牌，使用调试开卡解锁指定 `GL-*` 效果后重新刷出或重新附身暴食，使 CardManager 将解锁应用到该 Body。

基础数值：Space 无 CD；LMB `CD=2 / 耗血=10 / 伤害=20`；Q `CD=1 / 耗血=50 / 伤害=40`。可开启 `suppressPossessionDrain` 以专注验证表现与联动。

## 2. 三槽基线

| 输入 | 操作 | 期望 |
|---|---|---|
| Space | 首次使用 | 切至小猫：约 50% 体型、移速 ×2，持续 3 秒。 |
| Space | 小猫态再次使用 | 立即恢复普通魔猫，结束持续态。 |
| LMB | 无 `GL-A03` | 巨口快照在施放者脚下；显示完整 0.5 秒预警后结算，不随施放者或目标移动。 |
| Q | 小猫态使用 | 立刻恢复魔猫，前方约 1m 扇形仅命中最近合法 Enemy。 |
| Q | 命中合法 Enemy | 获得 `Overfed`；附身玩家同时将 Q 临时替换为目标的 Skill Ability。 |
| Q | 使用复制 Ability 一次 | 复制 Ability 触发后，Q 恢复为吞噬；Body 切换前未使用时也必须清除。 |
| 换身 | 任意持有状态 | 清除 `Overfed`、小猫态和未使用复制 Ability；已生成巨口仍可独立完成。 |

## 3. Overfed 与 Attack

| 条件 | 操作 | 期望 |
|---|---|---|
| 无 Overfed | LMB | 单次巨口：0.5 秒 Telegraph → 1 次结算。 |
| Overfed、无 `GL-A01` | LMB | 同一落点第一次巨口完成后，额外等待 0.5 秒，再在同一位置出现第二次巨口；随后消费 Overfed。 |
| Overfed + `GL-A01` | LMB | 主 / 第二巨口成对分布；主口按基础时序，第二口额外延迟 0.5 秒；只消费一次 Overfed。 |
| `GL-A02` 已解锁后 | Space → LMB | 下一次巨口伤害半径与 Telegraph 半径均 ×2，结算后消费强化。 |
| `GL-A01` + `GL-A02` + Overfed | Space → LMB | 两个巨口都使用 ×2 半径；不得生成第三或第四个巨口。 |
| `GL-A03` 已解锁 | LMB 指向地面 | 远程诱饵落点在施放时快照，仍保持 0.5 秒预警且不追踪。 |

## 4. 卡牌对照

| effectId | 解锁后检查 |
|---|---|
| `GL-M01` | 小猫形态速度额外提高；LMB 不再退出小猫态，但再次 Space、超时和 Q 仍会退出。 |
| `GL-A01` | 仅在消费 Overfed 时触发双口，第二口额外延迟 0.5 秒。 |
| `GL-A02` | 一次合法小猫化后，下一次 LMB 半径 ×2；双口时两口均继承。 |
| `GL-A03` | 将基础脚下巨口改为远程诱饵落点。 |
| `GL-S01` | 当前 Body 首次成功吞 Enemy 回复 50；吞弹、空挥与第二次吞 Enemy 不回复。 |
| `GL-S02` | 当前耐久低于 20% 的最近吞噬目标被处决，同时保留合法 Corpse 与复制资格。 |
| `GL-S03` | 当前只保留既有单枚低伤害 Projectile 吞噬近似行为；“全部合法飞行攻击 / 重型 / AoE”分类尚未实现，需单独验收。 |

退役卡：`GL-X01`、`GL-TG01` 已从 CardLibrary 完全移除，正常选卡池与调试开卡列表均不应再出现。

## 6. 已知限制

- Owner 已明确本轮不改全局输入：当前仍为 `Q = Special`、`E = Bullet Time`。
- `GL-S03` 的合法飞行攻击、重型攻击、范围攻击分类及扇形全量吞噬暂不处理；不要通过扩展 Projectile 分类系统绕过此限制。
- 巨口 Telegraph / Blast 已写入 `gluttony_new` Prefab 引用，但仍需 Play Mode 确认缩放与时序；Overfed active VFX 与复制 Skill 一次性 UI 仍未接入。
- `GL-S01` 首次回血按 **Body 生命周期** 计数：同体换出再附身不会重置；新 Body / 对象禁用后重建才会重置。
