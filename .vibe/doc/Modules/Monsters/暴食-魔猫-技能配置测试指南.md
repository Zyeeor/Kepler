# 暴食-魔猫 — 技能配置测试指南

> 生成：monster-dev-pipeline 阶段 B  
> Prefab：`Assets/Prefabs/Monster/gluttony_new.prefab`  
> Cheat：`MonsterCheatCatalog` → **Gluttony_new**

## 1. 入口

1. 打开 `CombatTest`（或当前战斗测试场景）
2. 确认 `MonsterPossessionCheat` 已挂 `MonsterCheatCatalog`
3. 建议关闭 `testDoublePickOnStart`，避免挡热键
4. Play → 按 Cheat 热键刷出 / 附身 **Gluttony_new**
5. 另刷木桩（任意可受伤怪）做目标

基础数值（CSV / TUNABLE）：移速 4、血量 60；Space 耗血 100 / CD 0；LMB 耗血 10 / CD 2 / 伤 20；Q 耗血 50 / CD 1 / 伤 40。

> Space 耗血 100 > 血量 60：附身测试时可开 `suppressPossessionDrain`，否则一发小猫化会把自己打空。

## 2. 三槽基线

| 输入 | 期望 |
|---|---|
| Space | 缩小约 50%、移速 ×2，约 3s 后恢复；不改受击层 |
| LMB | 鼠标地面点快照；红圈预警 → 延迟后咬合 AoE；不追踪目标 |
| Q | 前方扇形重咬；**仅命中单位**写入 Overfed；启动时打断小猫化 |
| 换身 | Overfed 清除 |

## 3. Overfed 联动（Q3=尺寸×2，Q4=仅命中）

| 步骤 | 期望 |
|---|---|
| Q 空挥 | 不获得 Overfed |
| Q 命中 | 获得 Overfed（Effect `Effect.Combat.GluttonyOverfed`） |
| 有 Overfed 再 LMB | 巨口覆盖尺寸 ×2，并消费 Overfed |
| 有 `GL-X01` + Overfed 再 LMB | 成对巨口（2 个），消费 Overfed；不再额外叠基线 ×2 |

## 4. 卡牌对照

| effectId | 解锁后检查 |
|---|---|
| `GL-A01` | LMB 主落点旁同步第二巨口（总数不超过 2） |
| `GL-A02` | Space 成功后，下一次 LMB 覆盖 ×2（生成后消耗） |
| `GL-A03` | LMB 最远指定距离变远（仍快照、不追踪） |
| `GL-M01` | 小猫态额外加速（不延长持续） |
| `GL-S01` | 本躯体**首次**成功吞噬单位回耐久；后续不再回 |
| `GL-S02` | 命中显式低耐久阈值（默认 20%）斩杀 |
| `GL-S03` | 可吞小型迎面弹并获 Overfed；激光/重型不吞 |
| `GL-X01` | 见 §3 |
| `GL-TG01` | Body 移速↑ + 巨口规模↑（单轴弱于专用卡） |
