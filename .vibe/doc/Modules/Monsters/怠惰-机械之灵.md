## 3. 技能明细

### 3.1 Space — 弹射起跳

- **状态**：`已开发但没资源`
- **Canonical 原文**（`02`）：朝地面开炮后弹射起跳；明显起跳前摇；腾空主要是表现，**不**获地面攻击免疫；Baseline `Reload 1 / hp cost 20 / damage 0`
- **行为规格**：
  - 输入：点按 / 施放即蓄势起跳并重定位落地
  - 基础无伤害；腾空不免疫地面攻击
  - `SL-M01`（遗下的守望者）：**合法起跳前**在起点部署短寿命**地雷**；触发时机与伤害为 Playable 参数（TUNABLE）。工程 `Sloth.LandingMine` 映射本卡；旧「守望者单次攻击装置」文案作废，以 Card Truth「地雷」为准
  - `SL-M02`（迟来的地鸣）：**合法落地后立刻**造成一次周围地面爆炸；未抵达合法落点不生成；**不**部署延迟装置、**不**形成持续脉冲区。工程 `Sloth.LandingBlast` 的即时 AoE 语义对齐本卡（旧「延迟脉冲」Module 文案作废）
- **数值**：见 §2；地雷 / 落地爆炸伤害半径 TUNABLE
- **Ability 脚本**：`EnemyAbility_SlothLaunch`
- **资源表**：见 §3.4；落地火焰、地雷与爆炸 VFX 多为占位。阶段 B 继续用现有挂载路径验收；资源行候选名为稳定合同，美术替换只改路径不改 `ResourceSetId`

### 3.2 LMB — 蓄力爆炸炮

- **状态**：`已开发但没资源`
- **Canonical 原文**（`02`）：按住蓄力；提高威胁 / 范围 / 伤害档；释放有明显后坐动画 / 反馈，**但不产生 Gameplay 位移**；「重型」本身不自动压弹；Baseline `Reload 0 / hp cost 5 / damage 2–100`
- **行为规格**：
  - 输入：长按蓄力、松手发射；轻触仍可合法发射
  - **后坐力（基线，无 Card）**：仅后坐**动画 / 镜头或姿态反馈**；**不**推动施放者位移、不击退自身、不写入位移 Ability。表现可读「重炮后坐」，Gameplay 站桩开火
  - 重型不自动压弹 / 清弹（除非持有 `SL-A05` 等到档压碎交互）
  - **Card 关系（取代工程独立 Scatter 权威）**：
    - `SL-A03`（圣骸分裂）：主炮在**命中或合法射程终点爆炸后**生成扇形散射子弹；数量随**本次蓄力时长**增加；子弹**不可再次分裂**；与 `SL-A04` **共享总实例上限**
    - `SL-A04`（众仆齐鸣）：**起手**将单发替换为同次施放的**固定扇形多发**；单枚伤害 = 本次重炮伤害 ÷ 小炮数量，最低 3；与 `SL-A03` 共享实例预算，不得无限派生
    - 工程 `Sloth.Scatter`（仅主弹命中敌人时散射、碎片忽略首目标）= **Legacy Evidence**；阶段 B 收敛到 `SL-A03`（爆炸后散射 + 蓄力定数量）。「碎片忽略首目标」可保留为 Playable 碎片碰撞细节（TUNABLE），不得另立与 Canonical 冲突的触发权威
  - `SL-A01`：更早进入更大炮体 / 爆炸档；轻触仍合法
  - `SL-A02`：放大飞行炮体与接触判定，**不**同步放大爆炸范围
  - `SL-A05`：达指定外显炮体档后，每发可压碎一枚更小迎面飞行攻击并继续；不处理激光 / AoE
- **数值**：见 §2；蓄力档 / 散射数量曲线 TUNABLE
- **Ability 脚本**：`EnemyAbility_SlothChargeShot`
- **Telegraph / 表现诉求**：Enemy 蓄力全程保持方向提示；档位变化提高威胁可读性（`03`）
- **资源表**：见 §3.4

### 3.3 Q — 木灵

- **状态**：`已开发但没资源`
- **Canonical 原文**（`02`）：向天空投出短寿命自动攻击木灵；跟随玩家、持续追击并攻击最近 Enemy 直到死亡；可被击毁；**不可 Possess**；不产 Corpse；**换身后按自身寿命继续**；达上限后新木灵替换最旧同源木灵；Baseline `lifetime 4s / Reload 1 / hp cost 50 / damage 5 / attack range 30`
- **行为规格**：
  - 输入：点按 Q 投掷部署
  - **全局同源上限（首轮）**：`3`（TUNABLE；`02` §15 明确不冻结 Drone 上限）。达上限时新木灵替换最旧同源木灵
  - **主人死亡 / 离身 / 换身**：木灵为已脱手独立生命周期（`01` §13 跨身：Sloth Drone 典型继续 + `02` 换身后按寿命继续）。主人 Body 死亡、玩家换走、Active Leave：**不**立刻销毁场上木灵，**不**强制提前终结协议；按自身寿命 / 被击毁 / 被上限替换自然终止。持有 `SL-S02` 时任一终止原因进入统一追击自爆（见 §4.1）
  - `SL-S01`：每层额外生成一台；超上限仍替换最旧；Stack Max 2
  - `SL-S02`（遗命不绝）：自然到期 / 被击毁 / 被上限替换 → **统一**锁定最近合法 Enemy 冲撞自爆；无目标则原地爆炸；每台只触发一次；**不**再分三套互斥终止演出权威（旧三分支作废）
  - `SL-S03`：提高攻击节奏；锁定持续追击最近合法 Enemy 至自身终止；不增数量
  - `SL-TG01`：提高普通攻击合法距离与木灵合法持续；单轴低于对应通用卡
  - 工程 `Sloth.DroneEconomy`：Canonical **无**同名卡 → **仅 Legacy**；不作为当前 Requirement，不得升格进牌池
  - 工程 `Sloth.DroneDeathBlast` → 部分对齐 `SL-S02`（须改为全终止原因统一自爆）
- **工程现状**：`SummonActor` + `SummonBolt`；死亡炸词条现状：脱离跟随→俯冲→炸→销毁（对齐目标见上）
- **Ability 脚本**：`EnemyAbility_SlothDrone`
- **资源表**：见 §3.4
