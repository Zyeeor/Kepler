## 3. 技能明细

### 3.1 Space — 弹射起跳

- **状态**：`已开发但没资源`
- **Canonical**：明显蓄势后重新定位；腾空主要是表现，**不**获地面攻击免疫
- **工程现状**：前摇起跳落地；`Sloth.LandingBlast` / `Sloth.LandingMine` 为工程词条（对齐目标见 §4）
- **资源**：落地火焰、地雷与爆炸 VFX 多为占位 / 制作中

### 3.2 LMB — 蓄力爆炸炮

- **状态**：`已开发但没资源`
- **Canonical**：按住蓄力；提高威胁 / 范围 / 伤害档；释放有明显后坐；「重型」本身不自动压弹
- **工程现状**：长按蓄力松手发射；`Sloth.Scatter`：**仅主弹命中敌人**时散射，碎片忽略首目标
- **开放**：CSV「爆炸会后坐力位移」是否为**无 Card 基线**后坐 → 见 Q2

### 3.3 Q — 木灵

- **状态**：`已开发但没资源`
- **Canonical**：
  - 短寿命自动攻击单位；可被击毁；**不可 Possess**；不产 Corpse
  - 换身后按自身寿命继续
  - 达上限后新木灵替换最旧同源木灵
- **工程现状**：`SummonActor` + `SummonBolt`；死亡炸词条：脱离跟随→俯冲→炸→销毁

### Enemy 行为基线（Canonical）

> 保持中远距离 → 合法时蓄力炮 → 木灵低于上限时部署 → 太近 / 站位不利时弹射重定位。
