## 2. 当前 Card System 核心设计合同

### 2.1 卡牌内容字段

当前每张正式卡包含以下内容字段：

- Card ID
- 明线名称
- 明线玩家可见描述
- 简短机制描述
- 分类
- 机制类别
- Stack Max
- 明线叠层后文本
- 暗线名称
- 暗线玩家可见描述
- 暗线叠层后文本
- 来源骨架

不新增稀有度，也不新增第五个 Flavor 字段。

### 2.2 明线 / 暗线

- **明线：** 西方黑暗神话、宗教、王权、誓约、审判、祭仪；避免武侠、仙侠、东方古风语感。
- **暗线：** AI / System / Protocol / Evaluation 式冷静技术语言。
- 两套语言描述的是**同一个 Gameplay**，机制必须唯一；幽默只来自两套认真语言之间的反差。

### 2.3 高频换身与敌我同源

- Card 首要服务 Combat + 高频 Possession。
- 敌人版本与玩家附身版本必须保持核心机制、核心 Payload 与视觉语义同源；允许 AI 使用时机、前后摇、冷却、瞄准与输入便利性不同。
- 已离手的 Projectile / AoE / 合法 Summon 等独立结果可按其生命周期继续；Body-bound 资源与状态不因普通 Card 擅自跨身。
- 成功附身后的新 Body 三槽按上游合同回到该 Body 的初始可用状态；Card 不应再通过无限刷新链制造额外闭环。

### 2.4 物理形态与 Interaction

- Card 可以改变范围、速度、数量、尺寸、时序、持续、输出形态、新派生、Interaction 与跨槽联动。
- Card 不能因为同属一个槽位，就把所有技能强行变成同一种物理类型。
- 基础 Projectile 默认不会彼此对冲；Cut / Reflection / 吞弹 / 压弹等只能由明确 Card 或高阶质变赋予。


### 2.5 当前Run作用域与Elite例外

- 9张基础通用Card：作用于本Run所有普通Enemy与所有普通Possessed Body。
- 7张Global Slot Card：作用于本Run所有普通Enemy与所有普通Possessed Body。
- Monster-Type Card：作用于对应类型普通Enemy与对应Possessed Body。
- Type Growth：作用于对应Sin普通Enemy与对应Possessed Body。
- **Elite完全排除当前Run以上四层Card效果**；即使Elite被玩家Possess，也只携带自身External Historical Build Snapshot，并执行正常满耐久 / 三槽初始化。

### 2.6 当前选卡时点

- `Opening Card`已删除 / Deprecated。
- Wave 1–7后各1次；Wave 8后连续2次；当前共9次三选一。
- 具体Offer算法以中心`Content/Encounter_CardOffer_Baseline_v1.0.md`为准。

## 3. 类型成长卡规则

当前采用 **A 方案**：

> 取消旧的“拿某罪普通怪物卡后，后台自动偷偷增加该罪基础属性”的隐性属性成长。

当前职责拆分：

- 取得某罪普通怪物类型卡：对应Sin `Investment +1`，计入遭遇倾向体系，但**不自动增加基础属性**；
- 取得该罪的类型成长卡：对应Sin同样 `Investment +1`，并显式让该罪整体发生基础形态成长。

类型成长卡统一规则：

- 七罪各 1 张，共 7 张；
- 全部 `Stack Max = 1`，取得一次即完整生效；
- 每张只动约 2 个非常直观的非伤害基础维度；
- 不做复杂条件、不做新资源、不做隐藏 HP / Damage 成长；
- 可以与基础通用卡使用同类属性轴，但**任何单轴强度都不得超过对应基础通用卡**；
- 类型成长的价值来自“多个较弱维度同时体现某罪整体气质”，而不是单轴压过全局基础成长；
- 敌人与玩家附身版本同源生效。

当前 7 张类型成长 Card ID：`PR-TG01`, `SL-TG01`, `GL-TG01`, `EN-TG01`, `WR-TG01`, `GR-TG01`, `LU-TG01`。

## 4. 全局槽位质变规则

全局槽位质变是 **Run 级常驻规则改变**。当前阶段不再限定最终必须是历史上的 6 张；先做满候选与当前认可设计，再通过实机和组合压力测试决定最终池子。

当前设计原则：

- 单张尽量做到“一眼能懂”，复杂度优先受控；
- 优先简单槽位联动、追加执行、动作衔接、明确 Interaction 等明显变化；
- 不做技能刷新闭环，不设计 `A → B → C → A` 自动回流；
- 追加施放属于原施放的派生结果，**不生成新的槽位使用事件**，避免再触发其他全局联动造成指数连锁；
- 同一个待触发状态不叠层；重复前置只刷新待触发状态；
- 终局按玩家常见取得 **3–4 张全局质变** 的组合强度进行安全测试；
- 当前弹反卡先保留强效果版本：在有效阶段可反射接触到的飞行攻击，**暂不人为限制单次反射数量**；具体可反射弹体资格、数值与必要限制留待实机测试。

当前 7 张全局槽位质变 Card ID：`GX-MA01`, `GX-AS01`, `GX-A01N`, `GX-MA02N`, `GX-AS02N`, `GX-MR01`, `GX-AR01`。

作用域：本Run所有普通Enemy + 普通Possessed Body；Elite不读取。
